第 3 关 · 自顶向下语法分析 LL(1)（第4章）

FIRST · FOLLOW · SELECT · 预测分析法 ｜ ⭐ 考试重点关，三大计算必考大题

🌳 1. 自顶向下：从树根往下长

🎯比喻：语法分析器拿到单词串，像拼乐高说明书一样，从"开始符号"这个总标题出发，不断套用语法规则向下展开，试图让整棵树的叶子恰好拼成输入串。语法分析分两大流派：自顶向下（本关，推导）和自底向上（下一关，归约）。

主旨：从开始符号（根）出发，反复使用产生式推导，自上而下建立语法树，使末端结点串 = 输入串。
核心难题：每一步"选哪条产生式？"选错了就得回溯。课件例：G: S→cAd, A→ab|a 识别 cabd：先猜 A→a 接着 d≠b 失败，回头换 A→ab 才成功——带回溯=不确定的分析，效率低不实用（4.4节）。

确定分析的条件：能根据当前输入符号唯一确定选用哪条产生式 ⇒ 无回溯。三类文法情景：
① 右部都以不同终结符开头（如 S→pA|qB）→ 看一眼输入就知道选谁；
② 右部以非终结符开头 → 需要算 FIRST（右部能推出什么开头）；
③ 含空产生式 A→ε → A"消失"后跟什么？需要 FOLLOW。

🧰 2. 三把钥匙：FIRST / FOLLOW / SELECT

定义对照（针对谁？能含什么？必考辨析）

🗣️ 人话版（先记住三个问题）：FIRST 回答"它能以什么打头？"；FOLLOW 回答"它后面能跟什么？"；SELECT 回答"眼前这个输入符号，该用哪条产生式？"。前两个是情报员，第三个是决策官——SELECT 拿着 FIRST/FOLLOW 的情报，拼出每条规则的"使用时机表"。

针对定义可含 ε？可含 #？
FIRST(α)符号串 α{a | α ⇒* a…}；若 α ⇒* ε 则 ε∈FIRST(α)✅可含ε；❌不含#
FOLLOW(A)非终结符 A{a | S ⇒* …Aa…}；A 是开始符号或跟在句尾则 # ∈ FOLLOW(A)❌绝不含ε；✅可含#
SELECT(A→α)产生式α⇏ε 时 = FIRST(α)；α 可推出 ε 时 = (FIRST(α)−{ε}) ∪ FOLLOW(A)可含 #（α⇒ε 时并入 FOLLOW(A)）、绝不含 ε（是选产生式的"时机"集合）

FOLLOW(A) 计算三规则（反复使用直到不再增大）

  1. A 是开始符号 ⇒ # ∈ FOLLOW(A)（# 是输入串结束符）。
  2. 有规则 B→αAβ ⇒ FIRST(β)−{ε} ⊆ FOLLOW(A)（A 后面跟的东西）。
  3. 有规则 B→αA，或 β ⇒* ε（A 实际在末尾）⇒ FOLLOW(B) ⊆ FOLLOW(A)（A 在哪 B 就在哪结束，B 的跟班也是 A 的跟班）。
🧠 记忆：FIRST 是"我能以什么开头"；FOLLOW 是"别人后面能跟我什么"；SELECT 是"什么时候该用这条规则"。

🔬 迷你例：3 条产生式手算三大集合（每步旁注"为什么"）

玩具文法 G[S]：① S→aAd　② A→bAS　③ A→ε（它能推出的最短句子是 ad：A 直接消失）。先算 FIRST：

算什么用哪条得到【旁注】为什么加这个符号
FIRST(S)①a右部 aAd 的第一个符号就是终结符 a——打头看得见，直接抄进集合
FIRST(A)②b右部 bAS 以终结符 b 打头，同理抄 b
FIRST(A)③ε这条右部整个就是 ε——A 能"凭空消失"，空串也算一种开头

结论：FIRST(S)={a}，FIRST(A)={b, ε}。

🔬 还是这个 G：手算 FOLLOW（三规则各露一手）

算什么用哪条规则得到【旁注】为什么加这个符号
FOLLOW(S)规则1：S 是开始符号#S 顶在最外层，输入读完的结束符 # 就跟在它后面
FOLLOW(A)规则2：在①里 A 后面跟着 ddA 出现在 aAd 中间，紧挨着它的 d 自然是 A 的"跟班"
FOLLOW(A)规则2：在②里 A 后面跟着 SaA 后面跟的是 S ⇒ 把 FIRST(S)−{ε}={a} 搬进 FOLLOW(A)
FOLLOW(S)规则3：在②里 S 待在末尾{a,d}S 在右部末尾 ⇒ "A 在哪收场，S 也可能跟着在那收场"，把 FOLLOW(A) 整包并入

结论：FOLLOW(A)={a,d}，FOLLOW(S)={#,a,d}。规则要反复套，直到集合不再变大。

🔬 还是这个 G：手算 SELECT ＋ 填分析表的一格

产生式用哪个公式结果【旁注】为什么
SELECT(S→aAd)右部推不出 ε ⇒＝FIRST(右部){a}右部不空，看它能以什么打头就够
SELECT(A→bAS)同上{b}打头是 b
SELECT(A→ε)右部可空 ⇒＝(FIRST−{ε})∪FOLLOW(A){a,d}A 一消失，接棒的就是它后面能跟的东西 ⇒ 借 FOLLOW(A) 当"使用时机"

填一格 M[A,d] 的完整推理：A 有两条产生式，逐条查——② 的 SELECT={b}，d 不在其中，跳过；③ 的 SELECT={a,d}，d 在其中，命中 ⇒ M[A,d]=A→ε。这就是"ε 产生式靠 FOLLOW 填表"的现场：A 自己不出场，让后面的 d 来点名。顺带：A 的两条 SELECT {b} 与 {a,d} 不相交 ⇒ 无冲突。

🎮 三大集合计算器（输入任意文法，自动算 + LL(1) 判定）

语法：大写字母(可带撇号如 E')=非终结符，其他单字符=终结符，@ 或 ε=空产生式，每行一条，| 分隔多个右部。第一行左部为开始符号。

LL(1) 文法：定义与判别五步

🗣️ 人话版：LL(1) 就是"瞄一眼就能下单"的好文法：只看当前 1 个输入符号，就能百分之百确定用哪条产生式，绝不犹豫、绝不回头（无回溯）。名字拆开：第 1 个 L＝从左到右读输入，第 2 个 L＝最左推导，(1)＝向前看 1 个符号。判别一句话：同一个非终结符各条产生式的"使用时机"（SELECT）两两不重叠。

充要条件：对每个非终结符 A 的任两条产生式 A→α、A→β，都有 SELECT(A→α) ∩ SELECT(A→β) = ∅

LL(1) 名字含义：第1个 L = 从Left 到右扫描输入；第2个 L = 用Leftmost（最左）推导；(1) = 只需向前看 1 个符号就能定产生式（LL(k) 看k个）。

判别五步（大题标准答题格式）：① 求能推出 ε 的非终结符集 → ② 各右部 FIRST(β) → ③ 各非终结符 FOLLOW(A) → ④ 各产生式 SELECT → ⑤ 按定义逐对检验交集。凡是 LL(1) 文法均可确定地自顶向下分析。

⚠️ LL(1) 的明显性质（必要非充分）：无左公共因子、无左递归、无二义性。反过来：不含左因子/左递归 不一定 就是 LL(1)！

🔧 3. 非 LL(1) → LL(1) 等价变换

招式一：提取左公因子

🗣️ 人话版：这两招都是把"让人犹豫的规则"改写成"一眼看清的规则"，只改写法、不改语言。提左公因子＝两条规则开头相同的部分先一起走完，把选择推迟到看清分歧之后（先上相同的头盘，吃完再选主菜）。消左递归：左递归 P→Pα 就像查字典循环——查"P"的释义写着"见 P 条"，永远翻不到底；程序照它写就会无限递归。改写成"先放不递归的 β，再让新帮手 P' 去接尾巴 α"，环就断开了。

A→αβ₁ | αγ（都从 α 开头 ⇒ SELECT 必相交）　⇒　A→αA'，A'→β₁|γ（把决定推迟到读完 α 之后）
一般式：A→δβ₁|…|δβₙ|γ₁|…|γₘ ⇒ A→δA'|γ₁|…|γₘ，A'→β₁|…|βₙ

例（课件例4.6）：S→aSb|aS|ε ⇒ S→aSS'、S'→b|ε、S→ε（ε 产生式要保留，别弄丢！）。隐含左公因子要先把非终结符代入展开（A→ad|Bc, B→aA|bB ⇒ A→ad|aAc|bBc 再提取）。注意：提取后可能仍不是 LL(1)、可能产生多余规则须删、个别文法有限步提不完；消除左递归/提公因子后的文法形式上可能不同，但互相等价（语言不变）。

招式二：消除左递归（重点公式，背！）

直接左递归 P→Pα|β（α≠ε，β 不以 P 开头）　⇒　P→βP'，P'→αP'|ε
一般式：P→Pα₁|…|Pαₘ|β₁|…|βₙ ⇒ P→β₁P'|…|βₙP'，P'→α₁P'|…|αₘP'|ε
变换前变换后
S→Sa|bS→bS'，S'→aS'|ε
S→Sc|Sabc|abc|bc|cS→abcS'|bcS'|cS'，S'→cS'|abcS'|ε
E→E+T|T, T→T*F|F, F→(E)|iE→TE'，E'→+TE'|ε，T→FT'，T'→*FT'|ε，F→(E)|i

间接左递归（A→Bβ, B→Aα 使 A ⇒⁺ A…）：先代入展开成直接左递归再消除。例：A→aB|Bb, B→Ac|d ⇒ 把 A 代入 B：B→aBc|Bbc|d，再对 B 消除左递归。
⚠️ 为什么必须消？左递归使 SELECT 相交（非LL(1)），还会让递归下降程序无限循环。消除后仍需检查多余规则、重判 LL(1)。

⚙️ 4. LL(1) 分析的两种实现

🗣️ 人话版：两种实现是同一思路的"手动挡／自动挡"——都拿预测分析表当攻略。递归下降：每个非终结符写一个函数，函数里按当前输入符号选分支（手动挡）；表驱动：一张 M[A,a] 表＋一个栈＋一个总控循环（自动挡）。表 M[A,a] 怎么读：行＝正要展开的非终结符 A，列＝眼前的输入符号 a，格子＝此刻该用的产生式；空白格＝这种组合不该出现，报错。

① 递归下降程序

每个非终结符写一个子程序；遇到多候选时按"当前输入符号 ∈ 谁的 SELECT"选产生式；遇到终结符就匹配并读下一个单词；遇到非终结符就递归调用它的子程序。优点：简单直观易构造；缺点：要求 LL(1)、递归调用多（慢、占空间）。Pascal、C 等编译器常用。

② 表驱动 LL(1) 预测分析程序（考试重点）

构造预测分析表 M：行=非终结符，列=终结符及 #。若 a ∈ SELECT(A→α) 则填 M[A,a]=A→α；填不进的空白格 = 出错入口（非 LL(1) 文法的表格会出现多重定义）。

总控程序（用分析栈 #E 开局）：栈顶 X，当前输入 a——

  • X 是非终结符：查 M[X,a] 取产生式，弹出 X，产生式右部逆序进栈（保证最左先匹配）；
  • X 是终结符：与 a 匹配则双双前进（弹栈+读下一个），否则报错；
  • 栈顶与输入同时到 #：接受！
📢 总控口诀：栈顶是非终结符 → 查表展开（弹栈＋右部逆序进栈，输入不动）；栈顶是终结符 → 比对（相同才弹栈＋读下一个，不同就报错）；栈顶与输入同时到 # → 接受。
💡 为何逆序进栈？栈是后进先出的，最左符号必须最后进栈才能最先出栈匹配。

🔬 迷你例：用栈"走"句子 ad#（前 3 步逐格旁注；栈底 # 在左，加粗描边的是栈顶）

开局：栈压入 # 和 S，输入指针指着 a。文法就用上面那个 G：S→aAd，A→bAS|ε。

第1步｜栈顶 S（非终结符），读 a → 查 M[S,a]＝S→aAd，弹出 S、d A a 逆序压栈 ⇒ 栈变 #dAa　【旁注】非终结符只"展开"、不消耗输入；a 最先要匹配，所以最后进栈

第2步｜栈顶 a（终结符），读 a → 对上暗号：弹 a、读下一个 ⇒ 栈 #dA，剩输入 d #　【旁注】终结符靠"比对"：一样才双前进，不一样立即报错

第3步｜栈顶 A（非终结符），读 d → 查 M[A,d]＝A→ε（上面刚手算过！），弹 A、ε 不进栈 ⇒ 栈 #d　【旁注】按 ε 展开＝把 A 空手弹出；A 敢不敢消失看 FOLLOW——d∈FOLLOW(A)，此时可以隐身

收尾：d 对 d 比对成功 → 栈剩 #，输入也剩 # → 两 # 碰面，接受！ad 是 G 的句子。
