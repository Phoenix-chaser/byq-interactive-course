🌳 4.1 确定的自顶向下分析思想课件 P2–P8

1. 语法分析方法分类（课件第2页原图）

语法分析子类特点 / 去处
自顶向下分析（本章）确定的LL(1) 分析，无回溯，4.1–4.3、4.5 节
不确定的带回溯，效率低，4.4 节
自底向上分析算符优先分析（课件原文印作"算法优先"）第 5 章
LR 分析第 6 章

🗣️ 人话版：自顶向下 = 从树根（开始符号）往下长叶子，用"推导"；自底向上 = 从叶子（输入串）往上归约到树根，用"归约"。本章只管前者的"确定"版本。

2. 定义与主旨（课件第3页）

定义：从文法的开始符号出发，反复使用文法的产生式，寻找与输入符号串匹配的推导。

语法树的构造：将文法的开始符号作为语法树的根，向下逐步建立语法树，使语法树的末端结点符号串正好是输入符号串。

自顶向下分析的主旨：对一个输入串，从文法的开始符号（根结点）出发，采用一切可能的办法，从上（根结点）而下地为输入串建立一棵语法树。

⚠️ 自上而下分析的主要问题：推导的每一步如何"选定产生式"？选对了直奔终点，选错了就要推倒重来——这一问，正是整个第 4 章的引线。

3. 开场例（课件第4页）：G：S→cAd，A→ab，A→a，识别 w=cabd

推导到 S⇒cAd 后，当前输入符号是 a，轮到展开 A。A 有两条候选：

选择推导得到结果原因
选 A→abS⇒cAd⇒cabdcabd成功与输入串 cabd 完全一致
选 A→aS⇒cAd⇒cadcad不成功第二个符号 d≠b，叶子拼不出 cabd

👉 两条产生式右部都以 a 开头（左公因子），光看当前输入符号 a 根本分不清该选谁——这就是"不确定"，解决办法要等到 4.2 / 4.3。

4. 确定分析的条件（课件第5页）🔥【考点】

从文法的开始符出发，如能根据当前的输入符号（单词符号）唯一地确定选用哪个产生式进行推导，则分析是确定的。

课件接着用三个文法层层递进地告诉你：想做到"唯一确定"，需要越来越强的工具。这是理解三大集合存在意义的钥匙：

5. 例1（课件第6页）：G1[S]：S→pA|qB，A→cAd|a，B→dB|b，输入 W=pccadd

最左推导过程（课件原过程）：

S ⇒ pA ⇒ pcAd ⇒ pccAdd ⇒ pccadd
步句型当前输入为何确定选这条
1S ⇒ pAp…S 的两条右部 pA / qB 以不同终结符 p / q 开头，见 p 选 S→pA
2pA ⇒ pcAdpc…A 的右部 cAd / a 以不同终结符 c / a 开头，见 c 选 A→cAd
3pcAd ⇒ pccAddpcc…又是见 c 选 A→cAd
4pccAdd ⇒ pccaddpcca…见 a 选 A→a，全部匹配，接受

G1[S] 的特点（课件原文）：⑴ 每个产生式的右部由终结符开头；⑵ 同一非终结符的不同产生式的右部由不同的终结符开头。
👉 对于这种文法，推导过程可以根据当前输入符号唯一确定选哪个产生式，即分析过程是确定的。

6. 例2（课件第7页）：G2[S]：S→Ap|Bq，A→a|cA，B→b|dB，输入 W=ccap

S 的右部以非终结符 A / B 开头，不能"看一眼"了。最左推导：

S ⇒ Ap ⇒ cAp ⇒ ccAp ⇒ ccap
步句型决策依据
1S ⇒ ApFIRST(Ap)={a,c}，FIRST(Bq)={b,d}，两集不交；当前输入 c ∈ FIRST(Ap)，故选 S→Ap
2Ap ⇒ cApA 的两条右部 a / cA 首符不同，见 c 选 A→cA
3cAp ⇒ ccAp仍见 c，再选 A→cA
4ccAp ⇒ ccap见 a 选 A→a，匹配成功

G2[S] 的特点（课件原文）：⑴ 产生式右部以终结符或非终结符开头；⑵ 同一非终结符的不同产生式的右部由不同的符号开头；⑶ 无空产生式。
👉 对于这种文法，选用哪个产生式不直观，关键是判断产生式右部推出的开始符号（集）——即 FIRST 集，分析过程可能是确定的。（这条文法将在 4.2 节当作 FIRST 的标准例题逐条算。）

7. 例3（课件第8页）：G3[S]：S→aA|d，A→bAS|ε，输入 W=abd

这条文法包含空产生式 A→ε。最左推导：

S ⇒ aA ⇒ abAS ⇒ abS ⇒ abd
步句型决策依据
1S ⇒ aA见 a，FIRST(aA)={a} 与 FIRST(d)={d} 不交，选 S→aA
2aA ⇒ abAS见 b，SELECT(A→bAS)={b}，选 A→bAS
3abAS ⇒ abS轮到 A，但当前输入是 d——A 只能"消失"：选 A→ε（d ∈ FOLLOW(A)，允许 A 空推）
4abS ⇒ abd见 d 选 S→d，叶子恰为 abd，接受

文法的特点（课件原文）——包含空产生式。👉 对于空产生式左部的非终结符，关键是判断该非终结符的后跟符号（集）——即 FOLLOW 集，分析过程可能是确定的。

🧰 课件第9页的承接语：要进行确定的自顶向下分析，文法要满足一定的限制，即文法是 LL(1) 文法。为此先研究三个定义：开始符号集 FIRST、后跟符号集 FOLLOW、选择集合 SELECT。——三个例子的"看首符 → 算 FIRST → 查 FOLLOW"正好对应三大集合的登场顺序。

🅰️ 4.2 之一 · 开始符号集 FIRST课件 P10–P12

定义 4.1（课件第10页原文）🔥【考点】

G=(VN, VT, P, S) 是上下文无关文法，α→β 是它的产生式（α∈VN，β∈(VN∪VT)*）：

FIRST(β) = { a | a∈VT 且 β ⇒* a…… }；若 β ⇒* ε，则规定 ε ∈ FIRST(β)。

直观地说：文法符号串 β 的开始符号集，是由 β 推导出的所有的终结符开头和可能的 ε 组成。

🗣️ 人话版（三问题之一）：FIRST 回答——"这个串能以什么打头？"打头的若是非终结符，就顺着它的产生式一路看下去，直到看见终结符为止；如果整个串能"蒸发"成空串，ε 也算一种打头方式。

例（课件第11–12页）：G2[S]：S→Ap，S→Bq，A→a，A→cA，B→b，B→dB，求每条规则右部的 FIRST

逐条推导（右部 → 打头分析 → 结果）：

右部 β分析过程（为什么）FIRST(β)
Ap（S→Ap）打头是 A；A→a 或 A→cA，A 推出的串以 a 或 c 开头；A 不能推 ε，故不用看后面的 p{a, c}
Bq（S→Bq）打头是 B；B→b 或 B→dB，B 推出的串以 b 或 d 开头；B 不能推 ε{b, d}
a（A→a）右部本身就是终结符 a 打头{a}
cA（A→cA）第一个符号是终结符 c，直接得 c{c}
b（B→b）终结符 b 打头{b}
dB（B→dB）第一个符号是终结符 d{d}

对比同一非终结符的各右部：FIRST(Ap)∩FIRST(Bq)={a,c}∩{b,d}=∅；FIRST(a)∩FIRST(cA)={a}∩{c}=∅；FIRST(b)∩FIRST(dB)=∅——所以例2 里分析 ccap 时每步都唯一确定。

结论（课件第12页）：针对无空产生式的文法 G，同一非终结符的任两个产生式的右部串的 FIRST 集无交集，即可采用确定的自顶向下分析。

🅱️ 4.2 之二 · 后跟符号集 FOLLOW课件 P13–P16

定义 4.2（课件第13页原文）🔥【考点】

G=(VN, VT, P, S) 是上下文无关文法，有产生式 B→xAy（A, B∈VN，x, y∈(VN∪VT)*）：

FOLLOW(A) = { a | S ⇒* …Aa…，a∈VT }；若有 S ⇒* …A（A 出现在句型末尾），则规定 #∈FOLLOW(A)。
注：'#' 做为输入串的结束符。

直观地说：非终结符 A 的后跟符号集，是由句型中紧跟 A 后的那些终结符（包括 #）组成。

🗣️ 人话版（三问题之二）：FOLLOW 回答——"A 站在句子里时，谁可能站在它后面？"它跟 A 自己的产生式无关，只跟"A 在别人的产生式里被安排在什么位置"有关。为什么需要它？当 A→ε 让 A 凭空消失时，分析器必须确认"消失后紧跟的输入符号"合不合法——消失后的世界由 FOLLOW 描述。

例（课件第14页）：G3[S]：S→aA|d，A→bAS|ε，用"找句型"的办法求 FOLLOW

目标依据的推导（句型）读出的结论
FOLLOW(S)由 S ⇒* S（S 自身就是句型，S 在末尾）# ∈ FOLLOW(S)
S⇒aA⇒abAS⇒abbASS⇒abbASaA（S 后面站着 a）a ∈ FOLLOW(S)
… ⇒ abbASd（中间的 S 换成 S→d，S 后面站着 d）d ∈ FOLLOW(S)
FOLLOW(A)由 S ⇒* aA（A 在句型末尾）# ∈ FOLLOW(A)
由 S ⇒* abAS ⇒* abAaA（A 后面站着 a）a ∈ FOLLOW(A)
… ⇒* abAd（S 换成 d 后 A 后面站着 d）d ∈ FOLLOW(A)
FOLLOW(S) = FOLLOW(A) = { #, a, d }

FOLLOW(A) 的计算方法（课件第15页，三规则反复使用）🔥【考点·必背】

  1. 如果 A 为文法的识别符号（开始符号），则规定 #∈FOLLOW(A)。
  2. 如果有形如 B→αAβ 的规则，则 FIRST(β) 的非空元素 ∈ FOLLOW(A)（即 FIRST(β)−{ε} ⊆ FOLLOW(A)）。
  3. 如果 β ⇒* ε，或者有形如 B→αA 的规则（A 在右部末尾），则把 FOLLOW(B) 加入 FOLLOW(A)。

反复使用上述规则，直到每个非终结符的 FOLLOW 集不再增大为止（不动点）。

例（课件第16页）：仍用 G3[S]，改用三规则机器地算 FOLLOW

算谁用了哪条规则计算结果
FOLLOW(A)A 在 S→aA 的末尾（规则3：FOLLOW(S) 并入）；A 在 A→bAS 中后跟 S（规则2：FIRST(S)−{ε} 并入）FOLLOW(S) ∪ {FIRST(S)−{ε}} = {#} ∪ {a,d}{#, a, d}
FOLLOW(S)S 是开始符号（规则1：#）；S 在 A→bAS 的末尾（规则3：FOLLOW(A) 并入）{#} ∪ FOLLOW(A) = {#} ∪ {#,a,d}{#, a, d}

两轮后不再增大，与第14页"找句型"的结果完全一致。FOLLOW 里永远没有 ε（后跟符号是看得见的终结符或 #）。

🎮 算完可用 第3关"三大集合计算器" 自动验证 FIRST / FOLLOW / SELECT，答案不一致时先查自己哪条规则漏用了。

🎯 4.2 之三 · 选择集合 SELECT课件 P17–P19

定义 4.3（课件第17页原文）🔥【考点】

G=(VN, VT, P, S) 是上下文无关文法，A→β 是它的产生式（A∈VN，β∈(VN∪VT)*）：

若 β 不能 ⇒* ε，则 SELECT(A→β) = FIRST(β)；
若 β 能 ⇒* ε，则 SELECT(A→β) = (FIRST(β) − {ε}) ∪ FOLLOW(A)。

🗣️ 人话版（三问题之三）：SELECT 回答——"眼前这个输入符号，轮到它时该不该用这条产生式？"右部推不出空：看它能以什么打头（FIRST）；右部能推出空：除了打头符号，还要算上"A 消失后允许跟谁"（FOLLOW 兜底）。SELECT 是站在产生式（规则）身上的集合——FIRST 站在符号串身上，FOLLOW 站在非终结符身上，三者针对对象不同，必考辨析。

例（课件第18页）：G3[S]：S→aA，S→d，A→bAS，A→ε，求全部 SELECT

产生式β 能否 ⇒*ε计算SELECT
S→aA否（a 打头推不空）FIRST(aA)={a}{a}
S→d否FIRST(d)={d}{d}
A→bAS否FIRST(bAS)={b}{b}
A→ε是(FIRST(ε)−{ε}) ∪ FOLLOW(A) = ∅ ∪ {#,a,d}{#, a, d}

检验"确定分析"：SELECT(S→aA)∩SELECT(S→d)=∅；SELECT(A→bAS)∩SELECT(A→ε)={b}∩{#,a,d}=∅——所以 G3 能做确定的自顶向下分析（例3 中 abd 每步都唯一确定，正与此吻合）。

结论（课件第19页）🔥【考点】

同一非终结符的不同产生式 A→α 与 A→β，若 SELECT(A→α) ∩ SELECT(A→β) = ∅，则一定可以进行确定的自顶向下分析。

📜 4.2 之四 · LL(1) 文法定义与五步判别课件 P20–P25

定义 4.4（课件第20页原文）🔥【考点】

一个上下文无关文法为 LL(1) 文法的充分必要条件是：对每个非终结符 A 的两个不同产生式 A→α 与 A→β，满足 SELECT(A→α) ∩ SELECT(A→β) = ∅。

LL(1) 名字的含义（课件原文）：

字含义
第一个 L从左到右扫描输入串
第二个 L分析过程用最左推导
(1)只需向前看 1 个输入符号便可决定选哪个产生式（类似地，LL(k) 文法需要向前看 k 个输入符号）

例（课件第21页）：G[S]：S→aAS，S→b，A→bA，A→ε，是否为 LL(1) 文法？

产生式计算SELECT
S→aASFIRST(aAS)={a}{a}
S→bFIRST(b)={b}{b}
A→bAFIRST(bA)={b}{b}
A→εβ=ε 可空：FOLLOW(A)。A 在 S→aAS 中后跟 S ⇒ FIRST(S)−{ε}={a,b} 并入；S 推不出 ε，无 FOLLOW(S) 并入 ⇒ FOLLOW(A)={a,b}{a, b}
SELECT(A→bA) ∩ SELECT(A→ε) = {b} ∩ {a,b} = {b} ≠ ∅

所以 G[S] 不是 LL(1) 文法——当 A 遇到输入符 b 时，不能确定选 A→bA 还是 A→ε 去推导（课件原文）。

LL(1) 文法判别五步（课件第22页）🔥【考点·大题模板】

  1. 求能推出 ε 的非终结符集（逐个非终结符检查能否 ⇒*ε）；
  2. 计算每个产生式右部 β 的 FIRST(β) 集；
  3. 计算每个非终结符 A 的 FOLLOW(A) 集；
  4. 计算每个产生式 A→β 的 SELECT(A→β) 集；
  5. 按 LL(1) 文法的定义判别（同一非终结符的各 SELECT 两两求交）。

🔬 大例题（课件第23页）：G[S]：S→AB|bC，A→b|ε，B→aD|ε，C→AD|b，D→aS|c —— 五步全算

第一步：谁能 ⇒*ε？（直接含 ε 产生式的先标"是"，再看右部全由可空符号组成的）

非终结符⇒*ε 否？理由
S是S→AB，A、B 都可空 ⇒ AB⇒ε
A是有 A→ε
B是有 B→ε
C否C→AD 中 D 不可空（D→aS|c 都终结符打头），C→b 不可空
D否D→aS|c 都终结符打头

第二步：FIRST(β)（课件第23页右侧数据）：FIRST(AB)={a,b,ε}（A 打头给 b，A 空则 B 打头给 a，两者全空得 ε）；FIRST(bC)={b}；FIRST(ε)={ε}；FIRST(b)={b}；FIRST(aD)={a}；FIRST(AD)={b,a,c}（A 给 b，A 空则 D 给 a、c）；FIRST(aS)={a}；FIRST(c)={c}。

第三步：FOLLOW（课件表格原文，可用三规则逐一复核）：

非终结符FOLLOW复核（规则来源）
S{#}开始符号给 #；S 只在 D→aS 末尾，FOLLOW(D) 也只有 #
A{a, c, #}A 在 S→AB 中后跟 B：FIRST(B)−{ε}={a}；B 可空再并 FOLLOW(S)；A 在 C→AD 中后跟 D：FIRST(D)−{ε}={a,c}（D 不可空）
B{#}B 只在 S→AB 末尾：并入 FOLLOW(S)={#}
C{#}C 只在 S→bC 末尾：并入 FOLLOW(S)={#}
D{#}D 在 B→aD、C→AD 末尾：并入 FOLLOW(B)、FOLLOW(C)，都只有 #

第四步：SELECT（课件第23页原文，右部可空的用并 FOLLOW 公式）：

产生式计算SELECT
S→AB(FIRST(AB)−{ε}) ∪ FOLLOW(S) = {a,b} ∪ {#}（AB 可空）{b, a, #}
S→bCFIRST(bC)={b}（不可空）{b}
A→ε(FIRST(ε)−{ε}) ∪ FOLLOW(A){a, c, #}
A→bFIRST(b){b}
B→aDFIRST(aD){a}
B→ε(FIRST(ε)−{ε}) ∪ FOLLOW(B){#}
C→ADFIRST(AD)（D 不可空 ⇒ AD 不可空）{b, a, c}
C→bFIRST(b){b}
D→aSFIRST(aS){a}
D→cFIRST(c){c}

第五步：判别（课件第24页）——按非终结符逐个求交：

非终结符两两交集结论
SSELECT(S→AB)∩SELECT(S→bC) = {b,a,#}∩{b} = {b} ≠ ∅冲突
A{a,c,#}∩{b} = ∅通过
B{#}∩{a} = ∅通过
CSELECT(C→AD)∩SELECT(C→b) = {b,a,c}∩{b} = {b} ≠ ∅冲突
D{a}∩{c} = ∅通过
由于 SELECT(S→AB)∩SELECT(S→bC)={b}≠∅ 且 SELECT(C→AD)∩SELECT(C→b)={b}≠∅，所以文法 G[S] 不是 LL(1) 文法。

4.2 小结（课件第25页总结原文）🔥【考点辨析】

集合针对谁可含 ε？可含 #？
FIRST 集符号串可含不含
FOLLOW 集非终结符绝不含可含
SELECT 集规则 / 产生式不含（ε 已被减掉）可含（经 FOLLOW 并入）

LL(1) 文法定义和判断：同一非终结符任两产生式 SELECT 两两不交。凡是 LL(1) 文法均可用确定的自顶向下分析。

📝 页 26 练习四题全解（课件原题）

练习(1)　G[S]：S→Sa|b|ε，求 FIRST(S)，是否为 LL(1) 文法？

用哪条分析贡献给 FIRST(S)
S→Sa打头还是 S：S 能推出以 a、b 开头或 ε 的串；S 为 ε 时 Sa ⇒ aa, b, ε（间接）
S→b终结符 b 打头b
S→ε右部就是 εε
FIRST(S) = {a, b, ε}。不是 LL(1) 文法：S→Sa 是直接左递归（左递归文法必非 LL(1)，见 4.3）；按定义验证也行——SELECT(S→Sa)=FIRST(Sa)={a,b}（Sa 含终结符 a，永远推不空），SELECT(S→b)={b}，交集 {b}≠∅。

练习(2)　G[S]：S→AB，A→a|ε，B→b|ε，求 FIRST(AB)，是否为 LL(1) 文法？

打头来源推导得
A 不空AB ⇒ aB ⇒ …a
A 空推、B 不空AB ⇒ B ⇒ bb
A、B 都空推AB ⇒ εε
FIRST(AB) = {a, b, ε}。是 LL(1) 文法：FOLLOW(A)={b,#}（A 后跟 B：FIRST(B)−{ε}={b}；B 可空再并 FOLLOW(S)={#}），SELECT(A→a)={a} 与 SELECT(A→ε)={b,#} 不交；SELECT(B→b)={b} 与 SELECT(B→ε)=FOLLOW(B)={#}（B 在 S→AB 末尾）不交；S 只有一条产生式，无对可交。

练习(3)　G[S]：S→a|b|ε，判断是否为 LL(1) 文法？

SELECT(S→a)={a}，SELECT(S→b)={b}，SELECT(S→ε)=(FIRST(ε)−{ε})∪FOLLOW(S)={#}（S 是开始符号）。三者两两不交 ⇒ 是 LL(1) 文法（语义上：见到 a 选 a、见到 b 选 b、见到结束符 # 让 S 空推）。

练习(4)　G[S]：S→aH，H→aMd|d，M→Ab|ε，A→aM|e，判断是否为 LL(1) 文法？（本题也是第3关大题演练题）

步结果依据
① ⇒*ε 集仅 M（有 M→ε）；A、H、S 均否A→aM|e、H→aMd|d 终结符打头
② FIRSTFIRST(S)={a}，FIRST(H)={a,d}，FIRST(M)={a,e,ε}，FIRST(A)={a,e}FIRST(M)=FIRST(Ab)∪{ε}=FIRST(A)∪{ε}
③ FOLLOWFOLLOW(S)={#}；FOLLOW(H)={#}（S→aH 末尾）；FOLLOW(A)={b}（A→…只在 M→Ab 中，后跟 b）；FOLLOW(M)={b,d}（M 在 H→aMd 中后跟 d；M 在 A→aM 末尾并 FOLLOW(A)={b}）三规则反复
④ SELECTS→aH：{a}；H→aMd：{a}；H→d：{d}；M→Ab：{a,e}；M→ε：FOLLOW(M)={b,d}；A→aM：{a}；A→e：{e}右部可空的仅 M→ε
⑤ 判别{a}∩{d}=∅（H）；{a,e}∩{b,d}=∅（M）；{a}∩{e}=∅（A）；S 单条全部不交
该文法是 LL(1) 文法。

✂️ 4.3 之一 · 提取左公因子课件 P27–P33

🎯4.3 引子（课件第27页）：确定的自顶向下分析要求给定语言的文法是 LL(1) 文法；某些非 LL(1) 文法可以等价变换为 LL(1) 文法。两种方法：提取左公因子、消除左递归。🗣️ 人话：这两招都是把"让人犹豫的规则"改写成"一眼看清的规则"，只改写法、不改语言。
🎮 第3关"三大集合计算器 / 预测分析动画"（level3.html）可自动验证变换前后三大集合与 LL(1) 判别结果。

引例（课件第28页）：例 4.6 文法 G[S]：S→aSb|aS|ε，是否为 LL(1) 文法？

先判别：SELECT(S→aSb)=FIRST(aSb)={a}，SELECT(S→aS)=FIRST(aS)={a}，两条 SELECT 都是 {a}，交集 {a}≠∅ ⇒ 该文法不是 LL(1) 文法（两条右部同以 aS 开头，正是"左公共因子"）。

1. 含左公共因子的文法（课件第29页）

若文法中含有形如 A→αβ|αγ 的产生式，称文法含有左公共因子。显然 SELECT(A→αβ) ∩ SELECT(A→αγ) ≠ ∅，文法不是 LL(1) 文法（两条右部同以 α 打头，FIRST 必相交）。

提取左公因子基本思想（课件原文）：通过改写产生式来推迟决定——读入足够多的输入、获得足够的信息之后，再做出正确判断。🗣️ 比喻：先上相同的头盘（公共前缀 α），吃完看清分歧点，再选主菜（β 还是 γ）。

2. 提取左公因子公式（课件第30页一般定义）

有左因子的文法：A→δβ₁|δβ₂|…|δβₙ|γ₁|γ₂|…|γₘ（每个 γᵢ 不以 δ 开头）
可改写为：A→δA'|γ₁|γ₂|…|γₘ，　A'→β₁|β₂|…|βₙ
（两条的特例：A→δβ₁|δβ₂ 提为 A→δA'，A'→β₁|β₂，等价于 A→δ(β₁|β₂)）

3. 例 4.6 完整解（课件第31页）：G[S]：S→aSb|aS|ε

步文法说明
先判别S→aSb|aS|εSELECT(S→aSb)∩SELECT(S→aS)={a}≠∅，不是 LL(1)
提左因子S→aS(b|ε)，S→ε公共前缀 aS 提出来，分歧部分 (b|ε)
引入 S'S→aSS'，S'→b|ε，S→ε用新非终结符 S' 承担被推迟的选择
再判别见下提取后是否就是 LL(1)？

提取后再查 S'：SELECT(S'→b)=FIRST(b)={b}；SELECT(S'→ε)=(FIRST(ε)−{ε})∪FOLLOW(S')，S' 只出现在 S→aSS' 末尾 ⇒ FOLLOW(S')⊇FOLLOW(S)，而 FOLLOW(S)={#,b}（S 是开始符号得 #；S→aSb 中 S 后跟 b 得 b）：

SELECT(S'→b) ∩ SELECT(S'→ε) = {b} ∩ {#,b} = {b} ≠ ∅ ⇒ 提取左公因子之后仍不是 LL(1) 文法。

4. 例 4.7（课件第32页）：G[A]：A→ad|Bc，B→aA|bB —— 隐含左公因子🔥【考点】

步文法说明
先判别A→ad|Bc，B→aA|bBFIRST(A 的右部)：ad 给 {a}，Bc 给 FIRST(B)={a,b}——两集在 a 上相撞。表面上 A 的右部没有公共前缀，但 B 能以 a 开头，所以 ad 与 Bc 隐含地共享左公因子 a，不是 LL(1)
代入展开（把隐含变明确）A→ad|aAc|bBc，B→aA|bB把 B 的两条右部代入 A→Bc 得 Bc⇒aAc / bBc，左公因子 a 显形
提公因子A→aA'|bBc，A'→d|Ac，B→aA|bBA 的三条按公式提 δ=a：A→aA'|bBc，A'→d|Ac；B 的右部 a、b 打头不同，不用提
判别SELECT(A→aA')={a} ∩ SELECT(A→bBc)={b} = ∅；SELECT(A'→d)={d} ∩ SELECT(A'→Ac)={a,b} = ∅；SELECT(B→aA)={a} ∩ SELECT(B→bB)={b} = ∅是 LL(1) 文法（课件答案：是）

5. 提取左公因子小结（课件第33页原文）🔥【考点】

  1. 经过提取左公因子之后，有些文法从非 LL(1) 变为 LL(1)，有的仍不是。因此，文法不含左公共因子只是 LL(1) 文法的必要条件（例 4.6 即反例）。
  2. 对于隐含的左公因子，可先等价变换为明确的左公因子之后再进行提取（教材 P78 例 4.7）。
  3. 经过提取左公因子之后，有时会使某些规则变为多余规则（教材 P79 例 4.8），故必须检查提取后的文法，去除多余规则。
  4. ⭐【了解】个别文法不能在有限步之内提取完左公因子（教材 P80 例 4.9）。

🔁 4.3 之二 · 消除左递归课件 P34–P43

1. 含左递归的文法（课件第34页）🔥【考点】

a) A→Aβ（A∈VN，β∈V*）—— 称直接左递归；
b) A→Bβ，B→Aα —— 单看每条都不含 A→A…，但 A ⇒ Bβ ⇒ Aαβ，即 A ⇒⁺ A…，称为间接左递归。

🗣️ 查字典循环比喻（呼应第3关）：左递归就像查字典时"P 的释义：见 P 条"——永远翻不到底。自顶向下分析从 A 出发，第一步又推回 A，树根底下还是树根，递归下降分析器照它写程序会陷入无限循环。

2. 为什么含左递归的文法不是 LL(1)（课件第35页证明）

以直接左递归为例，设有产生式 A→Aα　A→β（α、β 为任意语法符号串）。不难证明：

SELECT(A→Aα) = FIRST(Aα) ⊇ FIRST(A) ⊇ FIRST(β)；
SELECT(A→β) = FIRST(β)。
⇒ SELECT(A→Aα) ∩ SELECT(A→β) ⊇ FIRST(β) ≠ ∅

由于 A→Aα 和 A→β 的 SELECT 集相交，故含有左递归的文法不是 LL(1) 文法。结论：含有左递归的文法不能使用确定的自顶向下分析方法。

3. 左递归导致分析瘫痪的例子（课件第36页）

G[S]：S→Sa|b，则 L(G[S]) = { ban | n≥0 }

对输入串 baa 分析时：若选择 S→b 推导，则推不出 baa（只剩一个 a 没着落）；若选择 S→Sa 推导，则不知何时使用 S→b——两难，无法确定地分析。（这条文法消除左递归后见下文公式例。）

4. 消除直接左递归：公式与三个例子（课件第37–39页）🔥【考点·必背公式】

基本公式：对于产生式 P→Pα|β（串的特点 β α…α；α 不为 ε，β 不以 P 开头），可改写为：
P→βP'　　P'→αP'|ε
一般定义：P→Pα₁|Pα₂|…|Pαₘ|β₁|β₂|…|βₙ（每个 αᵢ≠ε，每个 βⱼ 不以 P 开头）可改写为：
P→β₁P'|β₂P'|…|βₙP'　　P'→α₁P'|α₂P'|…|αₘP'|ε

例1（P37）S→Sa|bS→bS'，S'→aS'|εP=S，α=a，β=b ⇒ S→bS'，S'→aS'|ε

5. 两点注意（课件第40页原文）

  1. 利用这种方法可以把直接左递归都消去，即换成右递归。
  2. 但是，这种方法并没有消除整个文法的左递归性——间接左递归仍会存在（所以还有下一小节的"代入法"）。

6. 消除间接左递归（课件第41–42页例）🔥【考点】

先判断：文法 G[A]：A→aB|Bb，B→Ac|d 中存在左递归吗？——有！A ⇒ Bb ⇒ Acb，即 A ⇒⁺ A…，这是间接左递归（没有任何一条 A→A… 的规则，但 A 绕道 B 又回到 A）。

思路（课件原文）：先将间接左递归等价变换为等价的直接左递归后，再消除左递归。三步走：

步文法动作
① 代入A→aB|Bb；B→aBc|Bbc|d将规则 1、2（A 的两条右部）代入规则 3 中的 A：Ac ⇒ aBc | Bbc，得 B 的直接左递归 B→Bbc|…
② 消直接左递归A→aB|Bb；B→aBcB'|dB'，B'→bcB'|ε对 B→Bbc|aBc|d 套公式：P=B，α=bc，β₁=aBc，β₂=d ⇒ B→aBcB'|dB'，B'→bcB'|ε
③ 查多余产生式同上消除多余产生式：无多余（课件原答案）
最终结果：A→aB|Bb，B→aBcB'|dB'，B'→bcB'|ε

复核：改写后 B 的右部以 a、d 打头，B 不再能绕回 A，A 的间接左递归链被剪断。

7. 消除左递归小结（课件第43页原文）🔥【考点】

  1. 消除左递归之后，有些文法从非 LL(1) 变为 LL(1)，有的仍不是。因此，文法不含左公共因子 / 不含左递归只是 LL(1) 文法的必要条件。
  2. 消除左递归之后，有时会使某些规则变为多余规则，故必须检查消除左递归之后的文法，去除多余规则。
  3. 消除左递归后的文法在形式上可能不同，但均等价（描述同一个语言）。

8. LL(1) 文法的等价条件与明显性质（课件第44页）🔥【考点】

LL(1) 文法：任两个产生式 A→α|β 都满足：
① FIRST(α) ∩ FIRST(β) = ∅（α、β 均不可空时的直观形式）；
② 若 β ⇒* ε，那么 FIRST(α) ∩ FOLLOW(A) = ∅。

LL(1) 文法有一些明显的性质：没有左公因子；不含左递归（另：LL(1) 文法亦无二义性，见课件第 69 页）——反向不成立，二者只是必要条件。

📝 页 45 练习全解（课件原题）：为下面文法消除左递归

原题：S→a|∧|(T)，T→T,S|S

解：S 的三条右部分别以 a、∧、( 打头，无左递归、无左公因子，不动；T→T,S 是直接左递归：认出 P=T，α=「,S」，β=S，套公式 P→βP'、P'→αP'|ε：

答案（课件原文）：S→a|∧|(T)，T→ST'，T'→,ST'|ε

顺手判别（自行验算）：SELECT(T→ST')=FIRST(S)={a,∧,(}；SELECT(T'→,ST')={,}；SELECT(T'→ε)=FOLLOW(T')。FOLLOW(T')⊇FOLLOW(T)（T' 在 T→ST' 末尾），FOLLOW(T)∋)（T 在 S→(T) 中后跟 )），解得 FOLLOW(T)=FOLLOW(T')={)}，故 SELECT(T'→ε)={)}，与 {,} 不交——改写后的文法是 LL(1) 文法，可直接进入 4.5 的两种实现。

↩️ 4.4 不确定的自顶向下分析思想（回溯）课件 P46–P47

定义（课件第46页原文）⭐【了解】

不确定的自顶向下分析也称带回溯的自顶向下分析。不确定是指：某个非终结符有多条产生式，而面临当前输入符无法唯一确定选用哪条产生式进行推导，只好逐个试探。当分析不成功时，则推翻分析、退回到适当位置重新试探其余候选可能的推导，直到把所有可能的推导序列都试完仍不成功，才能确认输入串不是该文法的句子。

例1（课件第47页）：S→xAy，A→ab|a，对输入串 w=xay

试探推导树走向结果
先试 A→abS⇒xAy⇒xaby，叶子 xaby与 w=xay 不符（多出 b），失败，回溯
回溯换 A→aS⇒xAy⇒xay，叶子 xay成功

原因（课件原文）：A 的两条产生式 A→ab 和 A→a 的右部 FIRST 集交集不为空（都含 a），从而引起回溯——本质上就是含有左公因子。
结论（课件原文）：效率低，代价高，不实用。所以才要花大力气研究 LL(1) 条件，把"试探"变成"一次选对"。

🧩 4.5 之一 · 递归下降 LL(1) 分析程序课件 P48–P50

🛠️课件第48页：确定的自顶向下分析有两种实现方法——递归下降 LL(1) 分析程序 和 表驱动的 LL(1) 预测分析程序。

递归下降程序的实现思想（课件第49页）🔥【考点·简答】

  • 对文法中的每个非终结符编写一个分析子程序，识别由该非终结符推出的串；
  • 当非终结符有多个产生式时，按当前输入符属于哪个产生式的 SELECT 集可唯一确定选择哪个产生式进行匹配；
  • 当识别到终结符时，与当前输入符号匹配，并读取下一输入符；
  • 当识别到非终结符时，则调用该非终结符相应的子程序（子程序名=非终结符名，递归由此而来）。

特点：优点、缺点、实用性（课件第50页原文）

维度内容
优点简单直观、易于构造
缺点对文法要求高，必须满足 LL(1) 文法；递归调用多，速度慢，占用空间多
实用性许多高级语言，如 Pascal、C 等编译系统常常采用此方法

🗂️ 4.5 之二 · 表驱动预测分析：构造预测分析表课件 P51–P55

构造预测分析表三步（课件第51页原文）🔥【考点】

  1. 把文法转变为 LL(1) 文法（消除左递归、提取左公因子）；
  2. 求出每条产生式的 SELECT 集；
  3. 依照 SELECT 集把产生式填入分析表：列——终结符与 '#'；行——非终结符；交点 M[A,a]：a∈SELECT(A→β) 则 A→β 放入 M[A,a]；无产生式的 M[A,a]——标记出错（表中空白即出错）。

🗣️ 查字典比喻：预测分析表就是一本"语法字典"——行是"词条"（非终结符），列是"检索字"（当前输入符），查 M[A,a] 直接翻到唯一答案（产生式）或翻到空白页（报错）。只要文法是 LL(1)，一查一个准，永不回溯。

实例（课件第52页）：算术表达式文法 G[E] 先消左递归

原文法 G[E]消除左递归后的 G'[E]
E→E+T│T
T→T*F│F
F→ i │ (E)		E→TE'
E'→+TE'|ε
T→FT'
T'→*FT'|ε
F→ i │ (E)

考察消除左递归之后的文法，无多余规则，那么它是否是 LL(1) 文法呢？——用 SELECT 逐条验（课件第53页原文 8 条全录）：

产生式SELECT验算依据
E→TE'{ (, i }FIRST(TE')=FIRST(T)=FIRST(F)={(,i}
E'→+TE'{ + }FIRST(+TE')={+}
E'→ε{ ), # }FOLLOW(E')：E' 只在 E→TE' 末尾 ⇒ 并 FOLLOW(E)={#,)}（E 开始符号得 #；F→(E) 中 E 后跟 ) 得 )）
T→FT'{ (, i }FIRST(FT')=FIRST(F)
T'→*FT'{ * }FIRST(*FT')={*}
T'→ε{ +, ), # }FOLLOW(T')=FOLLOW(T)：T 在 E→TE' 中后跟 E'，FIRST(E')−{ε}={+}，E' 可空再并 FOLLOW(E) ⇒ {+}∪{#,)}
F→(E){ ( }FIRST((E))={(}
F→ i{ i }FIRST(i)={i}

两两求交：E' 的 {+}∩{),#}=∅；T' 的 {*}∩{+,),#}=∅；其余行内仅一条非空 SELECT 或首符不同——G'[E] 是 LL(1) 文法。

请思考（课件第55页）⭐【了解·面试向】

  • 非 LL(1) 文法可否构造预测分析表？——可以照流程造，但因为存在 SELECT 相交的冲突，某个 M[A,a] 格子会被要求填入两条以上产生式（多重定义），查表不再唯一，分析器无从选择——这正是"非 LL(1)"在表上的特殊之处。
  • 利用预测分析表分析输入串 i+i*i 是否为文法的句子？——这就是下面 4.5 之三的 17 步全过程。

⚙️ 4.5 之三 · 总控程序：栈分析全过程 i+i*i（17步）课件 P56–P67

表驱动预测分析器的工作方式（课件第56页起的三列表）🔥【考点·大题】

  • 分析栈：初始压入 #E（# 在栈底，开始符 E 在栈顶）；
  • 剩余输入串：初始为 i+i*i#（结尾带 #）；
  • 总控循环：栈顶是非终结符 X → 查表 M[X,当前输入a] 得产生式 X→β，弹出 X，β 逆序进栈（ε 则什么都不压）；栈顶是终结符 a → 与当前输入比较：相同则弹出且读入下一输入符，不同则出错；栈顶 # 且输入也是 # → 接受；查到空白格 → 出错。

请思考（课件第68页）：为何要将规则逆序放入分析栈中？🔥【考点】

产生式 X→Y₁Y₂Y₃ 中，Y₁ 必须最先与输入匹配；而栈是后进先出的——谁在栈顶谁先被处理。所以必须按 Y₃、Y₂、Y₁ 的顺序压栈，让 Y₁ 最后进、处于栈顶最先被展开/匹配。顺序进栈会让 Y₃ 抢先出栈，分析立刻乱套。

🧭 4.5 之五 · 预测分析法实现步骤 + 4.6 出错处理课件 P69–P70 + P1 目录

LL(1) 文法的判别方法与实现步骤总结（课件第69–70页原文）🔥【考点·简答模板】

判别方法：① 求文法每个产生式右部符号串的 FIRST 集 → ② 求文法各个非终结符的 FOLLOW 集 → ③ 求文法每个产生式的 SELECT 集 → ④ 对文法 G 的每一个产生式 A→α₁|α₂|…|αₙ，若 SELECT(A→αᵢ)∩SELECT(A→αⱼ)=∅（i≠j），则文法 G 是一个 LL(1) 文法。
确定的自上而下分析法要求描述语言的文法是 LL(1) 文法；LL(1) 文法是无左递归、无二义性文法，通过消除文法左递归和提取公共左因子可将非 LL(1) 文法改写为 LL(1) 文法。

4.6 LL(1) 分析中的出错处理（课件目录第 6 节；正文以"空白即出错"落实）

  • 预测分析表的空白格就是出错标志（课件第54页注："表中空白处为出错"）：栈顶非终结符 X 面对输入 a 时若 M[X,a] 为空，说明任何产生式的 SELECT 都不包含这个处境——立即报告语法错误；
  • 栈顶终结符与当前输入不匹配、或栈底 # 与非 # 输入相遇（如上面 i)# 第 7 步），同样进入出错处理；
  • 排查思路：出错位置 = 出错步的"分析栈 + 剩余输入"，可据此定位源程序的行列号并调用出错恢复子程序后继续分析（表里也可预先在空白格登记恢复子程序）。
