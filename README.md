# 编译原理互动课堂 🎮

面向期末考试的《编译原理》闯关式互动学习网站。纯静态页面（HTML+CSS+原生 JS），无需安装、无需联网、无任何依赖。

## 怎么用

1. 打开 `index.html`（闯关地图）开始，按 1→6 关顺序学
2. 每关：生活化比喻讲解 → 可交互演示器（输入任意文法/正规式实时计算）→ 关末测验自动判分
3. 关末大题在文本框作答，点"复制全部答案"发给 AI 老师批改
4. 考前用 `cheatsheet.html` 速查表 + `final.html` 终极模拟卷

## 关卡对应章节

| 关卡 | 内容 | 课件章节 |
|---|---|---|
| 第1关 | 编译流程 + 文法与推导 | 第1、2章 |
| 第2关 | 词法分析：正规式→NFA→DFA | 第3章 |
| 第3关 | LL(1) 自顶向下分析 | 第4章 |
| 第4关 | LR 分析族（LR(0)/SLR/LR(1)/LALR） | 第5、6章 |
| 第5关 | 属性文法·符号表·四元式 | 第7、8章 |
| 第6关 | 运行时存储 + 代码优化 | 第9、10章 |

## 特色

- **真算法引擎**（`js/engine.js`）：FIRST/FOLLOW/SELECT、LL(1) 预测分析、LR 四种方法的项目集构造与分析表、NFA 确定化/最小化全部真实计算，输入任意文法即可验证手算结果
- 讲解遵循「先人话后定义、先小例子再正式、手算例题逐步旁注、多比喻多图」
- 学习进度自动保存在浏览器 localStorage
