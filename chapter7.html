1. 导引回顾：词法分析 vs 语法分析 🔥 考点

课件导引先抛出两个回顾问题：

问题一：编译的过程分为哪几个阶段？（第1章内容，本章的立足点）
词法分析 → 语法分析 → 语义分析 → 中间代码生成 → 代码优化 → 目标代码生成。前四章已经走完"认单词（第3章）、认结构（第4、5、6章）"，现在轮到语义分析登台。

问题二：词法分析和语法分析都是对符号串进行分析，二者有何区别？

词法分析语法分析
识别对象识别单词识别句子或者程序
"一个字母"的含义一个字母代表组成单词的一个符号（字符）一个字母代表一个单词
分析层面字符 → 单词单词 → 句子/程序
📌 记忆口径（原话照背）："词法分析中，一个字母代表组成单词的一个符号；而在语法分析中，一个字母代表一个单词。"这就是两级分析"字母口径"的区别，选择题爱考。另外两者的识别和分析方法不同：词法用正规式/有限自动机，语法用上下文无关文法/推导归约。
✅ 实际做法（引出全章主线）：实际编译器中，在进行语法分析的同时进行语义分析，并生成中间代码或目标代码——这套"搭便车"的做法就叫语法制导翻译（详见第 6 节定义）。

2. 语义分析的功能 🔥 考点

🗣️人话版：语义分析干两件事——先当安检员：句子语法没错，但意思不通也要拦下（"三个学生和一本书读书"？类型对不上）；再当翻译官：安检通过，就把程序翻译成中间代码或目标代码。

语义分析的功能 = 静态语义检查 + 执行翻译功能。

功能一：审查语法结构的静态语义（也称静态语义检查）

  • 类型检查：检查参与运算的操作数及其类型是否匹配（如实数和整数相加要不要转换，第 1 章课件的 inttoreal 例子就是它抓出来的，本站第 8 章页第 4 节有展开）。
  • 控制流检查：检查控制语句有合法的转向点——课件举例：C 语言中 goto 语句不允许转入 case 语句（转入后不知道该执行哪个分支，结构非法）。
  • 一致性检查：相同的作用域中标识符只能声明一次（同一作用域重复声明就是一致性错误）。

功能二：执行翻译功能

对于已经通过静态语义检查的程序，编译程序可以将其翻译成中间代码形式（第 8 章介绍）或目标代码（第 10 章介绍）。也就是说：先检查、后翻译，检查不过关就不翻。

3. 7.1 属性文法：给文法符号"贴便签" 🔥 考点

🗂️人话版：普通文法只回答"这串符号是不是合法表达式"，不回答"它等于几"。属性文法给每个文法符号贴便签（属性），再给每条产生式配便签怎么算的说明书（语义规则）——于是每认一层结构，就顺手算出一层值：结构认清的同时，语义也算出来了。

3.1 引入属性文法的目的 + 三元组（课件第 4 页）

引入属性文法的目的是借助该工具来说明程序设计语言的语义。属性文法（Attribute Grammar）在上下文无关文法的基础上做两点扩展：

  • ① 为每个文法符号关联有特定意义的属性（Attribute）；
  • ② 为文法的每个产生式关联一个语义规则集合，或称为语义动作（或者条件谓词）。

形式上，属性文法是一个三元组 A = (G, V, F)：

分量含义人话版
G上下文无关文法原来的"骨架"：管结构
V属性的有穷集合所有"便签"的集合
F关于属性的断言的有穷集合便签怎么算/怎么检查的规则

3.2 属性的概念与记号（课件第 5 页）

属性（Attribute）：可用来刻画一个文法符号的任何我们所关心的特性。课件列举的例子（都可能在选择题里出现）：

符号的值（如 E.val=27）｜ 符号的名字串｜ 符号的类型（int/real…）｜ 符号的偏移地址｜ 符号被赋予的寄存器｜ 代码片断，等等…

记号：文法符号 X 关联属性 a 的属性值，通过 X.a 访问——读作"X 身上那张便签 a 上写的值"。E.val 就是"E 的值"，d.lexval 就是"单词 d 由词法分析给出的值"。

3.3 语义规则：两种形态（课件第 6 页）

语义规则（Semantic Rule）：在属性文法中，每个产生式都关联一个语义规则的集合，用于描述如何计算当前产生式中文法符号的属性值，或附加的语义动作。属性文法中允许如下两种语义规则：

形态形式人话版
① 复写（copy）规则X.a := Y.b"照抄"：把 Y 的便签内容抄给 X（纯传递，不加工）
② 基于语义函数的规则b := f(c₁, c₂, …, cₖ)
或 f(c₁, c₂, …, cₖ)		"加工"：把孩子/自己的属性算一算得到 b；后一种没有左部，是纯动作（如 print）

其中 b、c₁、c₂、…、cₖ 都是该产生式中文法符号的属性。课件特别注明：实践中，语义函数的形式可以更灵活（不必拘泥于严格的一元/多元函数写法）。

4. 属性文法举例：P190 第3题完整表 🔥 考点

这是课件第 7 页给出的表达式求值属性文法（教材 P190 第 3 题），本章最重要的一张表，建议整表背下：

产生式语义动作【旁注】这条规则在干什么
S → E{ print(E.val) }分析完成，打印整个表达式的值
E → E₁ + T{ E.val := E₁.val + T.val }加法：两个孩子的值相加
E → T{ E.val := T.val }复写规则：照抄
T → T₁ * F{ T.val := T₁.val × F.val }乘法：两个孩子的值相乘
T → F{ T.val := F.val }复写规则：照抄
F → ( E ){ F.val := E.val }括号不改变值：照抄
F → d{ F.val := d.lexval }叶子：从词法分析给的值起步

课件注释两条：① E、T、F 均有属性 val；② d.lexval 是词法分析程序确定的属性值（数字单词的值在词法阶段就知道了，语义阶段直接取用——这体现了"编译各阶段接力"）。

5. 综合属性与 3*(5+4) 求值全过程 🔥 考点

5.1 综合属性

综合属性代表自下而上传递的信息——父结点的属性值由子结点的属性值计算出来，信息顺着语法树从叶子往根流。与之相对的还有继承属性（自上而下/从兄弟传信息；本章课件只出现了综合属性这一种）。

🧮人话版：综合属性就像手算 3*(5+4)——必须先算最里层括号：先有 5 和 4，才能算出 9；先有 3 和 9，才能算出 27。先有孩子的值，才有父亲的值，数值一层层"汇上去"，算到树根答案就出来了。所以求值方法就是对语法树做自下而上（后序）遍历，遇到能算的结点就按语义规则算一把。

5.2 课件原例：对表达式 3*(5+4) 的分析树自下而上（后序）遍历，执行相应语义规则，得到该表达式的一种求值过程

先画出带属性标注的语法树（文字版，每行末尾是逐步算出的属性值）：

S                       执行 S→E 的动作：print(27)
└─ E                    E.val = 27        ← E→T：照抄 T.val
   └─ T                 T.val = 27 = 3×9  ← T→T₁*F
      ├─ T (即T₁)       T₁.val = 3        ← T→F：照抄
      │  └─ F           F.val = 3         ← F→d：照抄词法给的值
      │     └─ d        d.lexval = 3      ← 词法分析确定
      ├─ *
      └─ F              F.val = 9         ← F→(E)：照抄括号里的值
         ├─ (
         ├─ E           E.val = 9 = 5+4   ← E→E₁+T
         │  ├─ E (即E₁) E₁.val = 5        ← E→T→F→d(5)
         │  ├─ +
         │  └─ T        T.val = 4         ← T→F→d(4)
         └─ )

再对照着看逐步求值表（后序遍历顺序，与课件第 9 页标注完全一致）：

步使用的产生式执行的语义规则结果
1F → dF.val := d.lexvald.lexval=3，F.val=3
2T → FT.val := F.valT.val=3
3F → dF.val := d.lexvald.lexval=5，F.val=5
4T → FT.val := F.valT.val=5
5E → TE.val := T.valE.val=5
6F → dF.val := d.lexvald.lexval=4，F.val=4
7T → FT.val := F.valT.val=4
8E → E₁+TE.val := E₁.val + T.val = 5+4E.val=9
9F → (E)F.val := E.valF.val=9
10T → T₁*FT.val := T₁.val × F.val = 3×9T.val=27
11E → TE.val := T.valE.val=27
12S → Eprint(E.val)输出 27
📌 规律：值总是"叶子先有（d.lexval 来自词法分析）→ 每上一层算一次（或照抄一次）→ 到根 S 处 print"。左下角 3 那条链是 3 次照抄（复写规则），右边括号里是 5+4=9，最后 3×9=27——整棵树的计算顺序就是后序遍历顺序。

6. 7.2 翻译模式 与 语法制导翻译 🔥 考点

6.1 翻译模式（Translation Scheme）概念

课件原文两条：

  • 翻译模式是适合语法制导语义计算的另一种描述形式（属性文法之外的另一种写法）；
  • 它可以体现一种合理调用语义动作的翻译算法——即不仅写"要做什么动作"，还写明"什么时候调用这些动作"（动作嵌入产生式中的位置有讲究），所以它更接近可实现翻译的算法。

6.2 语法制导翻译的概念（定义照背）

🔥 语法制导翻译：在语法规则的指导下，通过执行语义规则，完成对输入符号串的翻译。
🗣️人话版：语法规则是"导游路线"，语义规则是"每到一站干的事"。按路线走（推导/归约）、每到一站就干活（算属性/生成代码），走完全程，翻译也就完成了——这就是"语法驱动、语义搭车"。课件注明"后面会结合一道习题详细讲解"（本站认为该习题即下面的章末作业，见第 8 节）。

7. 7.3 分析和翻译程序的自动生成工具 YACC ⭐ 了解

  • YACC（Yet Another Compiler Compiler，"又一个编译器编译器"）是一个经典的生成语法分析器的工具。
  • YACC 生成的编译器主要是用 C 语言写成的语法解析器（Parser）；需要与词法解析器 Lex 一起使用，再把两部分产生出来的 C 程序一并编译，得到完整的编译器前端。
  • 课件注：YACC 本来只在 Unix 系统上才有，但现已普遍移植往 Windows 及其他平台。

⭐ 本站建议按"了解"级掌握此节（课件未标注级别）：记住"YACC 生成语法分析器、Lex 生成词法分析器、两者配合"这一句即可。

8. 章末作业：二进制小数转十进制（题目 + 完整解答）🔥 考点

8.1 题目（课件第 12 页，注"参P19413"——应为教材 P194 第 13 题）

给如下文法加上语义规则，使其能将任意一个二进制小数转换为十进制小数。如 (101.101)B = (5.625)D。

N → S₁ . S₂
S → S₁ B
S → B
B → 0
B → 1

（约定：N 是"整数部分.小数部分"；S 推出一串二进制位 B，且左边的 B 权重高——S→S₁B 是左递归写法。）

✍️ 先自己设计语义规则，再展开看完整解答（强烈建议先动手）

8.2 解答思路

💡思路拆成三句话：① 整数部分 S₁：每往左添一位，旧值×2 加新位——这就是"左移一位加本位"的竖式；② 小数部分 S₂：语法上和整数一样推（最靠小数点的位先出现、权重最高），所以先把它也当整数算出 val；③ 关键一步：小数串 "101" 当整数是 5，作为小数它代表 1×2⁻¹+0×2⁻²+1×2⁻³ = 5/2³ ——正好等于"整数值 ÷ 2^位数"！所以再给 S 配一个记录位数的属性 len，N 处一步除法搞定。

设 S 有两个综合属性：val（按整数算出的值）、len（二进位位数）。语义规则如下：

产生式语义规则【旁注】
B → 0B.val := 0单个位：值就是 0
B → 1B.val := 1单个位：值就是 1
S → BS.val := B.val；S.len := 1只有 1 位：照抄值，位数记 1
S → S₁ BS.val := S₁.val × 2 + B.val；S.len := S₁.len + 1添一位：旧串左移一位（×2）再加新位；位数加 1
N → S₁ . S₂N.val := S₁.val + S₂.val / 2^(S₂.len)
（可加动作 print(N.val)）		整数部分照用；小数部分=整数值÷2^小数位数

8.3 验证：(101.101)B = (5.625)D ✔（逐步求值，全部自底向上算）

整数部分 S₁ = 101（后序遍历执行规则）：

步使用产生式执行结果
1B → 1B.val := 1B.val = 1
2S → BS.val := 1；S.len := 1S(1)：val=1, len=1
3B → 0B.val := 0B.val = 0
4S → S₁BS.val := 1×2+0；S.len := 1+1S(10)：val=2, len=2
5B → 1B.val := 1B.val = 1
6S → S₁BS.val := 2×2+1；S.len := 2+1S₁(101)：val=5, len=3

小数部分 S₂ = 101：过程完全相同，得 S₂.val = 5，S₂.len = 3。

最后一步：N → S₁.S₂ 执行 N.val := S₁.val + S₂.val / 2^(S₂.len) = 5 + 5/2³ = 5 + 5/8 = 5 + 0.625 = 5.625 ✔ 与题目要求 (101.101)B=(5.625)D 完全吻合。

再抽两个数验算（确保规则对"任意"二进制小数都成立）：

  • (11.01)B：整数 S₁：1→(1×2+1)=3，len=2；小数 S₂：0→(0×2+1)=1，len=2；N.val = 3 + 1/2² = 3.25 ✔（11.01B = 2+1+0.25 = 3.25）
  • (0.1)B：整数 S₁：val=0；小数 S₂：val=1，len=1；N.val = 0 + 1/2¹ = 0.5 ✔
✅ 考试答法：写出上表 5 条语义规则即得全分；解释 2^(S₂.len) 时点明"小数串的整数值除以 2 的位数次幂"这句原理。本题同时演示了"语法规则指导下执行语义规则完成翻译"——正是第 6 节语法制导翻译的定义。
