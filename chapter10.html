1. 优化目标、手段与注意事项 🔥 考点

1.1 课件第 1 页逐句精讲（三句话简答必背）

关键词课件原句【旁注】讲透
优化目标提高目标程序质量，减少目标程序所占存储空间和运行时间"质量"落到两个硬指标上：省空间 + 省时间（二者可简称"时空效率"）
优化手段（途径）等价变换变换前后程序结果必须完全一样——优化不是改程序，是换一种更省的等价写法；这是优化的底线，任何优化技术都不能破坏
注意事项优化工作可在编译的任何阶段进行，但由于优化会延长编译时间，故应有选择地进行优化人话：优化不是越多越好——优化本身花时间（Debug 版编译快、Release 版编译慢跑得快，就是这个道理）；要挑收益大的优化做
🧹人话版：优化像出门前收拾行李——东西一件不少（等价变换：结果不变），但箱子更小、路上更省力（空间、时间）；收拾本身要花时间，所以只值得为长途旅行收拾（有选择地优化）。

2. 10.1 基本块的概念 🔥 考点

2.1 定义（名词解释照背）

🔥 基本块是指程序中一组顺序执行的程序段，只有一个入口语句和一个出口语句。

课件注：基于基本块可做各种局部优化工作——基本块是"局部优化"的基本单位（呼应 10.2 的局部优化=基本块内优化）。

🚄人话版：基本块 = 一段一口气跑到底、中间不打岔的代码：只能从第一句进（单入口）、从最后一句出（单出口），中途既没有岔路口（没有别的语句跳进来），也不半路下车（没有跳转跳出去）。像高铁直达区间：一站上车、终点下车、中途不开门。正因为块内"直达"，整个块可以当成一个整体放心地做优化（如调整语句顺序、删无用赋值）。

2.2 课件例一：赋值语句序列（"就是一个基本块"）

a := 20;
b := a + 20;
c := a * b;

【旁注】这三句顺序执行、没有任何转移：入口只能是第一句 a:=20，出口只能是最后一句 c:=a*b——标准的一个基本块。（顺便预演 10.3：块内 a 恒为 20，b=40、c=800 其实都能编译时算掉，这正是"基于基本块做局部优化"的味道。）

2.3 课件例二：IF 语句序列（含转移 → 不再是一个基本块，要"切"）

k := 1;
if k ≥ 10 then x := x + 1
           else y := y + 1

【旁注】这段里有条件转移（if 要分岔、then/else 还要跳回来汇合），不满足"一个入口一个出口"——所以它不是一个基本块，而是被 if 切开成若干块。划分的依据是入口语句的三条来源：

#入口语句来源对应本例
①程序的第一句k := 1
②能由转移语句转到的语句（跳转目标/带标号）else 分支 y := y+1（if 假分支跳到它）
③紧跟在转移语句之后的语句then 分支 x := x+1

按此切分：块1 = k:=1 与 if 条件判断（转移语句是"出口"，属于它所在的块并封口）；块2 = then 分支；块3 = else 分支。口诀：第一句、跳转目标、转移语句的下一句——三者皆入口。

3. 10.2 优化工作分类：两个维度 🔥 考点

2.5 手算示范：带 goto 的序列划分基本块（把"入口三来源"用全）

1:  i := 1
2:  t := 4 * i
3:  if i ≥ 100 goto L2
4:  i := i + 1
5:  goto L3
6:  L2: s := s + t
7:  L3: print(s)
行【旁注】为什么在这切
1程序第一句 → 入口来源①，起块1
2顺序执行，无转移 → 跟着块1
3转移语句是出口，属于块1并封口 → 块1={1,2,3}
4紧跟转移语句之后 → 入口来源③，起块2
5又是转移，封口 → 块2={4,5}
6带标号 L2，是跳转目标 → 入口来源②，起块3={6}
7紧跟转移之后的跳转目标 L3 → 起块4={7}

结果共 4 块。对照 2.3 的口诀自查：第一句、跳转目标、转移语句的下一句——三者皆入口；转移语句收尾封口。

课件给出两个分类维度（选择题最爱把两维度混在一起设错项，注意区分）：

分类维度类别【旁注】
按与机器的关系分两大类与机器无关的优化在中间代码层面就能做（如三大技术）——本章重点
与机器有关的优化涉及具体硬件（寄存器分配、指令选择等）
按优化与源程序的关系分局部优化（基本块内）范围最小、最好做（10.1 定义正是为它服务）
循环优化（循环内）循环体反复执行，优化收益被放大（外提、强度削减都在这）
全局优化（整个源程序范围）要跨基本块做数据流分析，开销最大
📌 答题提醒：问"与机器关系"答（无关/有关）；问"与源程序的关系"答（局部/循环/全局）——别把"循环优化"答到机器维度里去。

4. 10.3 三大优化技术举例 🔥 考点

4.1 合并常量运算（常量折叠）

🔥 思想（课件原句）：编译时就计算常量运算的值。
优化前：  i := 2 + 3 * 4          优化后：  i := 14
          r := 2 * 3.14                    r := 6.28

【旁注】操作数全是常量的运算，没必要留到运行时再算——编译器直接算出结果写死。运行时这两条"运算"彻底消失，省了时间和指令。（人话：能提前算好的账，出门前就算好。）

4.2 外提循环不变表达式（代码外提）

🔥 思想（课件原句）：与循环变量无关的表达式，拿到循环外部做，避免每次重复。
优化前：                        优化后：
i := 1;                         i := 1;
while i ≤ 100 do                t := a * b;      ← 外提：只算 1 次
begin                           while i ≤ 100 do
  x := a * b;    ← 不变量！      begin
  s := s + x;  i := i + 1         x := t;
end;                              s := s + x;  i := i + 1
                                 end;

【旁注】a*b 里没有循环变量 i，循环 100 次它算 100 次都得到同一个值——白算 99 次。外提到循环前只算一次，循环里直接用 t。注意判断标准：表达式里是否出现循环变量（出现了就变，不能外提）。（人话：不变的行李别每圈搬上搬下。）

4.3 消减运算强度（强度削弱）

🔥 思想（课件原句）：把强度大的运算改为强度小的运算。
优化前：                        优化后：
i := 0;                         i := 0;  t := 0;
while i < 100 do                while i < 100 do
begin                           begin
  x := 4 * i;    ← 每次做乘法      x := t;          ← 直接用上次的值
  …                                t := t + 4;      ← 乘法改成加法！
  i := i + 1;                     …
end;                              i := i + 1;
                                 end;

【旁注】"强度"指运算的代价：乘除比加减贵。本例中 i 每圈 +1，则 4*i 每圈恰好多 4——用"上次的结果 + 4"代替每次重做乘法，乘法就变成了加法。同思路的还有 x*2 → x+x、x/2 → x 右移 1 位。（人话：贵的运算换成便宜的等价运算，结果分毫不变。）

✅ 三大技术共同点：全部是等价变换（对照第 1 节"手段"）；前一个偏"局部/编译期算术"，后两个主战场是循环（对照 10.2 的循环优化）。建议按"思想原句 + 一个小例子"的格式背。

三大技术速记对比表

技术一句话思想最小例子常见战场
合并常量运算编译时就计算常量运算的值2+3*4 → 14局部（基本块内）
外提循环不变表达式与循环变量无关的表达式拿到循环外做循环内 a*b → 循环外 t:=a*b循环

5. 目标代码生成的定位 ⭐ 了解

课件原句：目标代码生成是编译的最终目的，涉及到具体的机器硬件知识，本章重点介绍与机器无关的代码优化工作。

  • 编译的最终目的：前九章所有分析、检查、优化，最终都要落到"生成目标代码"这一步才算交付。
  • 涉及具体的机器硬件知识（⭐展开了解即可）：目标机有多少寄存器、有哪些指令、什么寻址方式，直接决定生成什么样的代码——所以它属于"与机器有关"的范畴（呼应 10.2 分类），也是各机型编译器后端互不相同的原因。
  • 正因为它与机器强绑定，本章（及本课程）把重点放在与机器无关的代码优化上——也就是前四节的内容。

5.1 本章常考问法（按课件原句作答）

  • 问：代码优化的目标/手段是什么？答：目标——提高目标程序质量，减少目标程序所占存储空间和运行时间；手段——等价变换。
  • 问：优化应注意什么？答：优化可在编译的任何阶段进行，但会延长编译时间，应有选择地进行。
  • 问：什么是基本块？答：程序中一组顺序执行的程序段，只有一个入口语句和一个出口语句；基于基本块可做各种局部优化。
  • 问：优化分几类？答：按与机器的关系分（无关/有关）；按与源程序的关系分（局部-基本块内/循环-循环内/全局-整个源程序范围）。
  • 问：三大优化技术及思想？答：合并常量运算（编译时就算）、外提循环不变表达式（无关式拿到循环外）、消减运算强度（强度大改强度小）。

📖 本章一句话小结

优化目标=提高质量（省空间+省时间），手段=等价变换，注意=任何阶段可做但会延长编译时间、须有选择。基本块=顺序执行的程序段、单入口单出口（基于它做局部优化；转移语句是出口、跳转目标是入口）。分类两维度：与机器无关/有关；局部（基本块内）/循环（循环内）/全局（整个源程序）。三大技术：合并常量运算（编译时就算）、外提循环不变表达式（与循环变量无关的搬到循环外）、消减运算强度（强度大的改小，如乘改加）。目标代码生成=编译最终目的，涉及具体机器硬件（⭐了解）。
