🔤 2.2 符号和符号串（课件第 5~11 页）

字母表（Alphabet）——课件第 5 页

🔥 定义：字母表 Σ 是元素的非空有穷集合，字母表中的元素称为该字母表的符号，所以字母表也叫符号集。

课件思考题：字母表中的元素一定全是英文字母吗？——不一定！课件给的 5 个字母表例子：

#字母表说明
(1){a, b, c, d}4 个符号的小字母表
(2){a, b, c, ……, z}26 个小写字母
(3){0, 1}二进制字母表——符号可以是数字
(4)ASCII 字母表（一个字节）⭐【了解】256 个字符的编码表
(5)Unicode 字母表⭐【了解】容纳全世界文字的大字符集

注意定义里的两个限定词都要会抠：非空（至少有一个符号）、有穷（符号个数有限）。"任何语言程序都可以看成是一定字符集（字母表）上的字符串"（课件第 11 页原话），所以字母表是一切的出发点。

符号串（String）——课件第 6 页

🔥 定义：由字母表中的符号所组成的任何有穷序列，称为该字母表上的符号串。课件的递归式说法：

  • (1) ε 是 Σ 上的一个符号串，也叫空符号串（不含任何符号的串）。
  • (2) 若 x 是 Σ 上的符号串，a 是 Σ 中的元素，则 xa 是 Σ 上的符号串（往尾巴上接一个符号，还是符号串）。
  • (3) y 是 Σ 上的符号串，当且仅当它能由 (1) 和 (2) 导出——也就是说，所有符号串都是"从 ε 出发不断接符号"造出来的。
🔥🔥【考点】ε、∅（课件记作 ɸ）和 {ε} 的区别——年年必考的"三兄弟"：
· ε 是一个空符号串：它是一个"串"，内容为空，长度 |ε|=0；
· ∅（ɸ） 是不含任何元素的空集：它是一个"集合"，里面连一个串都没有；
· {ε} 是由空串组成的集合：它有一个元素，这个元素恰好是 ε。
一句话：∅ 里啥都没有，{ε} 里有 1 个"空气串"，ε 本身是个串不是集合。

注意（课件加粗强调）：符号串是有序的，ab 和 ba 不一样！串看的是"排列"，集合才不看顺序。

符号串的 5 个小概念：前缀 / 后缀 / 子串 / 逆转 / 长度——课件第 7 页

课件统一用 s = abc 做例子：

概念定义（课件原话）s = abc 的全部答案
前缀 / 头移走 s 的尾部的零个或多于零个符号ε, a, ab, abc
后缀 / 尾删去 s 头部的零个或多于零个符号ε, c, bc, abc
子串从 s 中删去一个前缀和一个后缀ε, a, b, c, ab, bc, abc
逆转将 s 中的符号按相反次序写出而得到的符号串cba
长度该符号串中的符号的数目，记 |s||abc| = 3，|ε| = 0

🔥 常考细节：前缀、后缀都算"删零个"的情况，所以 abc 自己、ε 都既是前缀又是后缀；空串 ε 的长度是 0，但它确实是"一个串"。

符号串的连接和方幂——课件第 8 页

  • 🔥 连接：设 x 和 y 是符号串，它们的连接 xy 是把 y 的符号写在 x 的符号之后得到的符号串。课件例子：x = ba, y = nana, xy = banana。（注意连接也不可交换：yx = nanaba，是另一个串。）
  • 🔥 方幂：同一个串自己连自己多少次。x⁰ = ε，x¹ = x，x² = xx，……，xⁿ = xⁿ⁻¹x。课件例子：设 x = ba，则 x¹ = ba，x² = baba，x³ = bababa，……
串的方幂口诀：0 次方是空串 ε，1 次方是自己，n 次方 = "n-1 次方再接一个自己"。

字母表的乘积与 n 次幂——课件第 9 页

  • 乘积：设 Σ₁、Σ₂ 是两个字母表，Σ₁Σ₂ = { ab | a∈Σ₁，b∈Σ₂ }即"第一个符号从 Σ₁ 里挑、第二个符号从 Σ₂ 里挑"组成的所有两符号串。
  • 课件例子：Σ₁ = {0,1}，Σ₂ = {a,b}，则 Σ₁Σ₂ = {0a, 0b, 1a, 1b}。
  • 课件思考题：交换律？Σ₁Σ₂ == Σ₂Σ₁ ？——不满足！反例就用上面的：Σ₂Σ₁ = {a0, a1, b0, b1}，和 {0a, 0b, 1a, 1b} 完全不同（串有序，第一个位置挑谁的符号结果不一样）。
  • n 次幂（递归定义）：⑴ Σ⁰ = { ε }；⑵ Σⁿ = Σⁿ⁻¹Σ　(n ≥ 1)即"自己接连乘 n 次"。注意 Σ⁰ 是由空串组成的集合 {ε}，不是空串也不是空集——正好复习上面的三兄弟。
  • 课件例子：Σ₁³ = {000, 001, 010, 011, 100, 101, 110, 111}（Σ₁={0,1} 连乘 3 次 = 所有 3 位二进制串，共 2³ = 8 个）。

正闭包与克林闭包——课件第 10 页

🔥 正闭包：Σ⁺ = Σ ∪ Σ² ∪ Σ³ ∪ Σ⁴ ∪ ……
🔥 克林闭包（Kleene Closure）：Σ* = Σ⁰ ∪ Σ⁺

人话：Σ⁺ 是"长度至少为 1"的所有符号串全家；Σ* 再加上空串 ε，是"包括空串在内"的所有符号串全家。两者只差一个 ε！

课件例子（Σ = {0,1}）：

{0,1}⁺ = {0, 1, 00, 01, 10, 11, 000, 001, 010, 011, 100, ……}   ← 没有 ε
{0,1}* = {ε, 0, 1, 00, 01, 11, 000, 001, 010, 011, 100, …}   ← 多一个 ε 打头

🔥 这对闭包后面天天用：第 3 章的正规式 r* 与这里同源；"标识符 = 字母(字母|数字)*"这类式子的 * 就是克林闭包的意思。

从字母表到语言：一条主线——课件第 11 页

课件用一张层级图收束本节：字母表（集合）→ 字符 → 串 → 语言（集合的组合）。两句话必须记住：

  • 任何语言程序都可以看成是一定字符集（称为字母表）上的字符串（有限序列）——一个 C 程序，就是 ASCII 字符集上的一个很长的符号串。
  • 任何一个语言程序主要由语法和语义两个方面定义——语法管"长得对不对"（本章的事），语义管"意思对不对"（第 7、8 章的事）。

🧩 2.3 文法和语言的形式定义（课件第 12~28 页，本章最重）

课件第 12 页只提了一个问题：如何实现语言结构的形式化描述？——"形式化"就是用数学符号严格写出来、不含糊。接下来课件用"英语句子"的例子一路引出：规则 → 推导 → 文法四元组 → 语言。

规则（重写规则 / 产生式 / 生成式）——课件第 13 页

🔥 定义：规则是形如 α→β 的 (α, β) 有序对，其中 α 称为规则的左部，β 称为规则的右部。读作"α 定义为 β"。三个名字（重写规则、产生式、生成式）说的是同一个东西。

课件例：用 10 条规则描述一个英语句子（这就是第 4 页问题 1 问的"P19 页 BNF 文法"，数一数正好 10 条）：

<句子>   →  <主语> <谓语> <间接宾语> <直接宾语>     ①
<主语>     →  <代词>                                ②
<谓语>     →  <动词>                                ③
<间接宾语> →  <代词>                                ④
<直接宾语> →  <冠词> <名词>                          ⑤
<代词>     →  He                                    ⑥
<代词>     →  me                                    ⑦
<冠词>     →  a                                     ⑧
<动词>     →  gave                                  ⑨
<名词>     →  book                                  ⑩

它的"终点"句子就是：He gave me a book.（他给了我一本书）——10 条规则，搭出一个英语句子。

句子的推导：用规则一步步"生成"句子——课件第 14 页

🔥 定义：句子的推导就是用规则（产生式）按一定方式去推导或产生句子的过程。下面把课件第 14 页的完整推导逐步重演，右列标出每步用的规则：

<句子>
 ⇒  <主语> <谓语> <间接宾语> <直接宾语>     用①
 ⇒  <代词> <谓语> <间接宾语> <直接宾语>       用②
 ⇒  He <谓语> <间接宾语> <直接宾语>           用⑥
 ⇒  He <动词> <间接宾语> <直接宾语>           用③
 ⇒  He gave <间接宾语> <直接宾语>             用⑨
 ⇒  He gave <代词> <直接宾语>                用④
 ⇒  He gave me <直接宾语>                    用⑦
 ⇒  He gave me <冠词> <名词>                用⑤
 ⇒  He gave me a <名词>                      用⑧
 ⇒  He gave me a book                        用⑩   ✓ 全终结，句子诞生

看清楚套路：每一步只挑一个尖帽子成分（非终结符），用它的规则把它重写掉，直到一个尖帽子都不剩。这个过程反过来（从句子收回到 <句子>）就是后面要讲的"归约"。

温故知新（二）：符号串集合的运算 + 课件练习——课件第 17 页

上一页复习的是"单个串"的运算，这一页把运算搬到"串的集合"上。设 U、V 是 Σ* 的子集：

🔥 连接（积）：UV = { αβ | α∈U 且 β∈V }　（U 里取一个串接上 V 里取一个串，所有可能）
🔥 指数：Vⁿ = VV…V（n 个 V 连乘），V⁰ = { ε }
🔥 闭包：V* = V⁰ ∪ V¹ ∪ V² ∪ V³ ∪ ……
🔥 正闭包：V⁺ = VV* = V¹ ∪ V² ∪ V³ ∪ ……

🔥 课件练习（原题）：U: { A, B, …, Z, a, b, …, z }（52 个字母），V: { 0, 1, …, 9 }（10 个数字），求 UV、V*、U(V)*、U⁺。分步解答：

小题分步求解答案
UVU 中每个字母分别接上 V 中每个数字：52×10 = 520 个长度为 2 的串，字母在前、数字在后{A0, A1, …, z9}（共 520 个）
V*V⁰ ∪ V¹ ∪ V² ∪ …：先含空串 ε，再含一切数字串（1 位、2 位、3 位……）{ε, 0, 7, 00, 10, 007, 2024, …}（ε + 全部数字串）
U(V)*一个字母 U，后面跟 (V)* 即 0 个或多个数字{x, x1, a01, temp2 形} —— 字母开头、后随任意多个数字（标识符的雏形！）
U⁺U¹ ∪ U² ∪ …：长度至少为 1 的纯字母串{a, ab, abc, …}（一切非空字母串）

顺手记：U(V)* 正是程序语言"标识符"的骨架——字母打头，后面字母数字随便跟。第 3 章正规式会再次见到它。

🔥 定义 2.1：文法是一个四元组——课件第 18 页（本章第一定义）

G = ( VN, VT, P, S )
元名称课件定义白话
VN非终结符(NonTerminal)集非空有穷；语法成分——代表某个语言的各种子结构所有"半成品"成分的名单（尖帽子们）
VT终结符(Terminal)集非空有穷；且 VT ∩ VN = Φ（不含公共元素）、VT ∪ VN = V（并起来称文法的字母表 V）最终成品的名单；两个集合不许有交集
P规则的集合每个元素是 α→β，读作"α 定义为 β"；其中 α ∈ (VT∪VN)⁺ 且 α 中至少有 VN 中元素的一个出现；β ∈ (VT∪VN)*；α 称左部(Left Part)，β 称右部(Right Part)法律条文集合；左部不能为空且必须含非终结符，右部可以为空（可以推出 ε）
S开始符号(Start Symbol)S ∈ VN；代表文法所定义的语言，至少在规则左侧出现一次推导的总入口、树根

🔥 三处必考的"抠字眼"：① 两个集合都非空有穷且不相交；② P 中规则左部 α 属于正闭包 ⁺（不能是空串）且至少含一个非终结符，右部 β 属于克林闭包 *（可以为空）；③ S 必须在某条规则的左部出现过，否则整棵推导树根本发不了芽。

文法的简写约定 G[E]——课件第 19 页

课件例：一个简单算术表达式的文法，四元组全写很啰嗦：

G = ( {E}, {id, +, *, (, )}, P, E )
P = { E → E + E
      E → E * E
      E → ( E )
      E → id   }

约定：只写产生式，缩写成一行（| 读"或"）：

🔥 G[E]:　E → E + E | E * E | ( E ) | id

方括号里的 E 就是开始符号。通常我们只给文法的简写形式——课件思考题：依据简写如何识别 VN、VT、P 和 S？

  • S：G[ ] 方括号里那个符号（没写方括号时，就是第一条规则左部的符号）；
  • VN：所有在规则左部出现过的符号（本例 {E}）；
  • VT：只在规则右部出现、从没当过左部的符号（本例 {id, +, *, (, )}）；
  • P：竖线拆开后的每一条（本例 4 条）。

说明：课件后面的推导里把 id 简写成 i，i 就代表一个标识符（id），两者是一回事。

文法如何定义语言？——推导——课件第 20 页

🔥 方法：把产生式看成重写规则，把当前符号串中的非终结符用其产生式右部的串来代替。课件用 G[E] 演示了两条完整推导：

推导一：得到句子 (i + i)

E ⇒ (E)         用 E→(E)
  ⇒ (E + E)     用 E→E+E
  ⇒ (i + E)     用 E→i
  ⇒ (i + i)     用 E→i          ✓ 句子：(i + i)

推导二：得到句子 i + (i + i) * i

E ⇒ E * E           用 E→E*E
  ⇒ E + E * E       用 E→E+E    （替换最左的 E）
  ⇒ i + E * E       用 E→i
  ⇒ i + (E) * E     用 E→(E)
  ⇒ i + (E + E) * E 用 E→E+E
  ⇒ i + (i + E) * E 用 E→i
  ⇒ i + (i + i) * E 用 E→i
  ⇒ i + (i + i) * i 用 E→i      ✓ 句子：i + (i + i) * i

同一个文法，走的路子不同，就得到不同的句子——文法像"造句机器"，规则是零件，推导是装配过程。

🔥 定义 2.2：直接推导与直接归约——课件第 21~22 页

课件定义（原话整理）：已给文法 G=(VN,VT,P,S)，令 α, β ∈ (VN∪VT)*，且 A→γ ∈ P。此时，由符号串 v = αAβ 能够直接推出符号串 w = αγβ，我们称：

  • 符号串 αγβ 是符号串 αAβ 的直接推导；
  • 符号串 αAβ 是符号串 αγβ 的直接归约；
  • 记作：αAβ ⇒ αγβ

人话：推导是"把某个非终结符 A 按它的一条规则换成右部 γ"；归约就是同一个动作反过来看——把"长得像某规则右部"的串 γ 收回成左部 A。α 和 β 是 A 前后"不动的地方"（上下文）。

课件例（G[S]: S→0S1, S→01，注意课件此处把两条规则并排写在 S 下）：

(1) v = 0S1,  w = 0011,   有  0S1 ⇒ 0011,   使用规则 S→01
(2) v = S,    w = 0S1,    有  S   ⇒ 0S1,    使用规则 S→0S1

课件思考题：请问在上述推导中 α 和 β 是什么？分步解答：

  • 例 (1)：v = αAβ = 0S1 ⇒ αγβ = 0011。对照得 A = S、γ = 01，所以 α = "0"（S 左边的 0），β = "1"（S 右边的 1）——S 被改写时，它左边的 0 和右边的 1 原地不动。
  • 例 (2)：v = αAβ = S ⇒ αγβ = 0S1。这里 A = S、γ = 0S1，S 前后都没有别的符号，所以 α = ε（空串），β = ε（空串）。

🔥 定义 2.3 / 2.4：推导（多步）与广义推导——课件第 22 页

  • 定义 2.3（推导）：若有 α₁, α₂, …, αₙ ∈ (VN∪VT)*，且 α₁ ⇒ α₂ ⇒ … ⇒ αₙ₋₁ ⇒ αₙ，则称 αₙ 是 α₁ 的推导，记作 α₁ ⇒⁺ αₙ（走了至少一步，n ≥ 2）。
  • 定义 2.4（广义推导）：若在推导关系 α₁ 到 αₙ 中允许 α₁ = αₙ（一步都不走也行），则称 αₙ 是 α₁ 的广义推导，记作 α₁ ⇒* αₙ（走了零步或任意多步）。
🔥【考点】⇒、⇒⁺、⇒* 三个记号的区别（课件第 22 页直接发问）：
· ⇒ ：直接推导，用一条规则，恰好走 1 步；
· ⇒⁺：推导，走1 步或多步（至少一步）；
· ⇒*：广义推导，走0 步或多步（允许原地不动，所以任何串和自身都有 α ⇒* α）。
三者是"一步 / 至少一步 / 零步及以上"的递进关系。

🔥 定义 2.5、2.6：句型、句子和语言——课件第 23 页

已给文法 G = (VN, VT, P, S)：

  • 🔥 句型：若 S ⇒* α，α ∈ (VN∪VT)*，则称 α 为文法 G 的句型——从 S 出发能推出来的任何串（里面可以还夹着非终结符）。
  • 🔥 句子：若 S ⇒* α，α ∈ VT*，则称 α 为文法 G 的句子——推到全终结符为止的句型。
  • 🔥 语言：文法 G 所对应的语言是文法一切句子的集合：L(G) = { α | α ∈ VT*，且 S ⇒* α }

课件例：i + i 和 i + (i + i) * i 都是 E → i | E+E | E*E | (E) 的句子（当然，推导路上经过的 E+E、i+E 等都叫句型）。

课件思考题：L(G) 和 (VT)* 之间的关系是什么？——L(G) 是 (VT)* 的子集：(VT* 是终结符拼出的所有串，L(G) 只是其中能从 S 推导出来的那部分。比如 E 的文法推不出 i i 或空串，它们在 (VT)* 里却不在 L(G) 里。）

文法的作用：语言的有穷描述——课件第 24 页

课件思考题：文法 E→E+E | E*E | (E) | id 可以派生出多少个句子？——无穷多个！E 递归地包含 E，可以无限套娃：(id)、(id+id)、((id+id)*id)、……

这正是文法的价值：以有限的规则描述无限的语言现象。

有限（文法这边）无限（语言那边）
产生式集合、终结符集合、非终结符集合——三样全部有穷可以导出无穷多个句子（当然 L 也可以是有穷的，比如后面的 G6 只有 4 个句子）
L(G) = { α | S ⇒* α，α ∈ VT* }

文法 → 语言：例 G1、G2——课件第 25~26 页

例 1（课件第 25 页）：求文法 G1 定义的语言。G1:　S→bA，A→aA | a

S ⇒ bA ⇒ ba                      （A 只用 A→a）
S ⇒ bA ⇒ baA ⇒ baa               （A 用一次 A→aA 再用 A→a）
S ⇒ bA ⇒ baA ⇒ baA ⇒ … ⇒ baa…a   （A→aA 用 n-1 次，最后 A→a）
L(G1) = { baⁿ | n ≥ 1 }           ——b 打头，后面至少一个 a

例 2（课件第 26 页）：求文法 G2 定义的语言。G2:　S→AB，A→aA | a，B→bB | b

S ⇒ AB ⇒ aB ⇒ ab                     （A、B 都各自一步到位）
S ⇒ AB ⇒ aAB ⇒ … ⇒ a…aB ⇒ a…ab       （A 先造 m 个 a）
S ⇒ AB ⇒ … ⇒ a…aB ⇒ … ⇒ a…abb…B ⇒ a…ab…b   （B 再造 n 个 b）
L(G2) = { aᵐbⁿ | m, n ≥ 1 }           ——先是若干个 a，后是若干个 b，两边个数互不相干

解题套路（以后求语言全用这招）：看每个非终结符各自负责造什么——A 负责"a 的队伍"，B 负责"b 的队伍"，S 只负责把两队拼起来，所以 m 和 n 独立取值。

语言 → 文法：不唯一 + 等价文法——课件第 27 页

课件又给了一个也能产生 {aᵐbⁿ | m,n≥1} 的文法 G2':　S→ACB，A→aA | a，C→aCb | ab，B→bB | b（C 专门造"a 和 b 一样多"的一段，A、B 再往两边加塞，合起来照样是先 a 后 b、个数随意）。由此给出两条重要结论：

  1. 🔥 给定一个文法 G，就可以从结构上唯一地确定其语言 L(G)——文法到语言是"一对一"这一侧是确定的；
  2. 🔥 给定一种语言 L，能确定其文法，但这种文法可能不是唯一的——语言到文法是"多对一"。于是有：
定义（课件编号 2.5 处）：若 L(G2) = L(G2')，则称文法 G2 和 G2' 是等价的。

🔥 文法 ↔ 语言互求四连例——课件第 28 页（构造题标准题型）

例 A：构造文法 G3，使 L(G3) = { aⁿbⁿ | n ≥ 1 }。分步思路：a 和 b 必须一样多，那就让它们"一对一地同时产生"——每用一次递归规则就同时放出一个 a 在左、一个 b 在右：

G3:  S → aSb | ab
验证: S ⇒ ab            （n=1）
      S ⇒ aSb ⇒ aabb    （n=2）
      S ⇒ aSb ⇒aaSbb ⇒ aaabbb   （n=3）✓ aⁿbⁿ

例 B：有文法 G4: S→aSb, S→ab，它确定的语言是什么？——和例 A 完全同一个文法！所以 L(G4) = { aⁿbⁿ | n ≥ 1 }。（这题在教你：别看见"求语言"就慌，拿递归规则"转几圈"验证即可。）

例 C：已知语言 L(G) = { abⁿa | n ≥ 1 }，试给出其文法。分步思路：两头 a 固定不动，中间夹一串 b——两头的 a 直接写死，中间交给一个专门产 b 的非终结符 B：

G5:   S → aBa,   B → bB | b        （B 右递归产 b）
G5':  S → aBa,   B → Bb | b        （B 左递归产 b，效果相同）
验证: S ⇒ aBa ⇒ aba （n=1）；S ⇒ aBa ⇒ abBa ⇒ abba （n=2）✓ abⁿa

两个答案都对——这正好印证课件第 27 页的结论"给定语言，文法不唯一"（G5 和 G5' 等价）。

例 D：有文法 G6: S→aB | bB，B→a | b，它确定什么语言？分步：S 先放出第一个符号（a 或 b），B 再放出第二个符号（a 或 b），两步各 2 选 1：

S ⇒ aB ⇒ aa    S ⇒ aB ⇒ ab
S ⇒ bB ⇒ ba    S ⇒ bB ⇒ bb
L(G6) = { aa, ab, ba, bb }      ——所有长度为 2 的 a/b 串（有穷语言！只有 4 个句子）

🏛️ 2.4 文法的类型（课件第 29~30 页）

🔥 乔姆斯基（Chomsky）把文法分为四类——课件第 29 页

对四元组 G = (VT, VN, S, P) 中产生式的形状逐步加以限制，就得到四型文法：

类型产生式限制（课件原话）别名白话
0 型α→β，α, β ∈ (VN∪VT)*，α 至少有一个非终结符短语文法几乎不加限制，只要左部里有非终结符就行
1 型|α| ≤ |β|（右部不比左部短），但 S→ε 可以例外；等价看法：αAβ → αγβ 是 1 型文法的一个产生式上下文有关文法改写不许"越改越短"；A 想变成 γ，得看左右两边的上下文 α 和 β 答不答应
2 型A → β，A ∈ VN，β ∈ (VN∪VT)*上下文无关文法（CFG）左部只能是单独一个非终结符——A 想改写就改写，不看上下文
3 型A → aB 或 A → a，A, B ∈ VN，a ∈ VT*右线性文法 / 正规文法右部最多"一个终结符 + 最多一个非终结符"，且非终结符只能乖乖站在右边
🔥 "上下文有关 / 上下文无关"的名字由来（对照 1 型的 αAβ→αγβ 与 2 型的 A→β）：1 型里非终结符 A 的改写被它的左邻 α、右舍 β "管着"——只有处在 α_β 这个环境里才许变成 γ，这就是"上下文有关"；2 型里 A 是唯一的左部，左边是啥右边是啥都无所谓，随到随改，这就是"上下文无关"。程序语言的绝大部分语法结构用 2 型描述，所以后面第 4~6 章的语法分析全部围绕 2 型文法展开。

四型文法的"逐级包含"关系——课件第 30 页

课件强调：四种文法之间的关系是将产生式作进一步限制而定义的——限制越加越多，能描述的语言越来越少。四种文法之间的逐级"包含"关系：

3 型 ⊂ 2 型 ⊂ 1 型 ⊂ 0 型
正规文法 ⊂ 上下文无关文法 ⊂ 上下文有关文法 ⊂ 短语文法
（限制最严）                            （几乎无限制）

🔥 人话记忆：号码越大，限制越严，队伍越小。每个 3 型文法天然是 2 型、1 型、0 型；判断题型给文法问"是几型"时，从最严的 3 型开始试，试到第一个满足的就是答案（说"G 是 2 型"通常指它满足 2 型但未必满足 3 型）。

⭐【了解】四种文法分别对应四种自动机（0 型→图灵机、1 型→线性有界自动机、2 型→下推自动机、3 型→有限自动机），本章只要求记住名称与包含关系，自动机部分第 3 章接触有限自动机。

🌳 2.5 上下文无关文法及其语法树（课件第 31~34 页）

语法树的定义与 (i+i) 的树——课件第 31 页

🔥 定义：语法分析树是 2 型文法的句型推导的图形表示，简称语法树。课件用 E→i | E+E | E*E | (E) 画了句子 (i+i) 的推导树（无论按什么顺序替换，最后长成同一棵树）：

E ⇒ (E) ⇒ (E+E) ⇒ (i+E) ⇒ (i+i)     （先展开括号里最左的 E）
E ⇒ (E) ⇒ (E+E) ⇒ (E+i) ⇒ (i+i)     （先展开括号里最右的 E）
两条路殊途同归，都是下面这棵树：
        E
      / | \
     (  E  )
       /|\
      E + E
      |   |
      i   i

🔥 课件金句：语法树表示了一个句型种种可能的不同推导过程——一棵树把"所有替换顺序"一网打尽，所以后面分析句型时我们宁画树不写推导。

画树规则（从推导得树）：开始符号做根；每用一次规则 A→γ，就给结点 A 添上 γ 里从左到右的儿子；终结符是叶子不再展开；从左到右读叶子就是那个句型。

🔥 最左推导与最右推导（规范推导）——课件第 32 页

  • 最左推导：任何一步 α ⇒ β 都是对 α 的最左非终结符进行替换的——记号 ⇒lm。它与最右归约对应。
  • 最右推导：每步都替换最右的非终结符——记号 ⇒rm。最右推导又称规范推导，与最左归约（规范归约）对应。

课件例（句子 (i+i)，两种推法对照，注意每步替换的是哪个 E）：

最左推导:  E ⇒(lm) (E) ⇒(lm) (E+E) ⇒(lm) (i+E) ⇒(lm) (i+i)
分步: ① E→(E)      ② 括号里最左的 E→E+E
      ③ 现在最左的 E（+左边那个）→i
      ④ 剩下的 E→i                     ✓ (i+i)

最右推导:  E ⇒(rm) (E) ⇒(rm) (E+E) ⇒(rm) (E+i) ⇒(rm) (i+i)
分步: ① E→(E)      ② 括号里的 E→E+E
      ③ 最右的 E（+右边那个）先→i
      ④ 剩下的 E→i                     ✓ (i+i)

🔥 考点提醒："最右推导 = 规范推导"，"最左归约 = 规范归约"这两对名字是第 6 章 LR 分析的地基（LR 分析就是规范归约），现在必须把对应关系背牢。

🔥 例：i*i+i 的最右及最左推导——课件第 33 页（解答课件留白处）

题目（课件原题）：文法 G: E→i | E+E | E*E | (E)，给出句子 i*i+i 的最右及最左推导。分步解答：

先想结构：i*i+i 只能切成 (E*E) + E（左边的 E 推成 i*i，右边的 E 推成 i）。

最左推导（每步替换当前最左的非终结符）:
  E ⇒ E+E ⇒ E*E+E ⇒ i*E+E ⇒ i*i+E ⇒ i*i+i
  分步: ① E→E+E（开局定型"+"在外）
       ② 当前最左的 E（+左边）→E*E
       ③ 最左的 E→i    ④ 下一个最左 E→i    ⑤ 最后的 E→i

最右推导（每步替换当前最右的非终结符）:
  E ⇒ E+E ⇒ E+i ⇒ E*E+i ⇒ E*i+i ⇒ i*i+i
  分步: ① E→E+E       ② 当前最右的 E（+右边）→i（先定型末尾）
       ③ 剩下的 E→E*E  ④ 最右 E→i    ⑤ 最后的 E→i

对照口诀：最左推导"从左往右一点点收"（先定型左半边），最右推导"从右往左收"（先定型右半边）。🎮 这道题在第 1 关的推导模拟器（level1.html）里有互动版，去亲手推一遍。

🔥 文法的二义性——课件第 34 页

课件思考题（第 33 页问、第 34 页答）：一个句型是否对应一棵唯一的语法树呢？——不一定！课件马上用同一个文法的句子 i*i+i 给出两棵语法树：

推法一（第一步用 E→E*E，乘在外层）：E ⇒ E*E ⇒ i*E ⇒ i*E+E ⇒ i*i+E ⇒ i*i+i，把 i*i+i 理解为 i*(i+i)：

🔥 定义（课件原话）：若一个文法存在某个句子对应两棵不同的语法树，则称此文法是二义性文法。
所以 E → i | E+E | E*E | (E) 是二义性文法（i*i+i 就是"呈堂证供"）。
三点必须想明白（考试爱挖的坑）：① 二义性说的是文法的性质，不是句子好看不好看；树一对应"乘法优先级低"、树二对应"乘法优先级高"——同一句子两棵树意味着两种不同计算顺序。② 判二义性只需找一个句子画出两棵不同的树即可定罪；但要证明一个文法无二义性，必须对所有句子都论证唯一（难得多，了解即可）。③ 消除二义性的常用办法是改写文法、引入优先级层次（如把 E 拆成 E、T、F），第 4 章构造 LL(1) 表达式文法时会亲眼看到这种改写，详见第 4 章。

🔎 2.6 句型的分析（课件第 35~40 页）

什么是句型分析 + 两大流派——课件第 35 页

🔥 句型分析：就是识别一个符号串是否为某文法的句型，是某个推导的构造过程。句型分析算法分为两类：

方法方向课件对应章节
自顶向下的分析方法从树根（开始符号）往叶子推第 4 章
自底向上的分析方法从叶子往树根归约第 5、6 章

自顶向下的分析方法——课件第 36 页

  • 思想（课件原话）：对一个输入串，从文法开始符号（根结点）出发，采用一切可能的办法（复用各种规则进行推导），从上（根结点）而下地为输入串建立一棵语法树。
  • 问题（课件加粗发问）：在推导过程中如何选择规则？——一个非终结符往往有多条规则，选错了就得回头。

课件例：G: S→cAd，A→ab | a，构造输入串 cabd。分步走：

① 从 S 开始，唯一规则 S→cAd：句型变成 cAd，最左的 c 恰好对上输入的 c ✓
② 轮到 A，它有两条规则，先试 A→a：句型变成 cad
     下一个输入符号是 b，可句型这里该匹配 d 了 → ✗ 失败，回溯
③ 换 A→ab：句型变成 cabd
     c ✓ a ✓ b ✓ d ✓ → 全部对上，cabd 是该文法的句子 ✓

🔥 "先猜错、再回溯"太笨了，怎么一眼选对规则？靠 FIRST 集 / FOLLOW 集——详见第 4 章（自顶向下的确定性分析、LL(1) 文法都在那里展开）。

自底向上的分析方法——课件第 37 页

  • 思想（课件原话）：对一个输入串，逐步进行"归约"，试图归约到文法的开始符号。（"规约"即课件用字，规范写法为"归约"。）
  • 问题（课件加粗发问）：在归约过程中如何选择可归约串？——串里哪一段能收？收哪一段才对？

课件例（同一个文法 G: S→cAd，A→ab | a，输入 cabd）反向走：

① 从左往右扫描 cabd，先拿下 c、a、b；
② 发现栈顶的 ab 恰好是规则 A→ab 的右部 → 把 ab 归约成 A，得到 cAd
③ cAd 恰好是规则 S→cAd 的右部 → 再归约成 S
④ 归约到了开始符号 S：cabd 是句子 ✓（和自顶向下的结论一致）

呼应第 1 关的比喻：自底向上归约像收拾桌上的一摞摞碗——每次认准"最左边能一把端走的那摞"（它有专门的名字：句柄，马上定义），收走一摞可能又叠出新的一摞，直到桌上只剩一个大盘子 S。"选哪一摞"就是课件问的"如何选择可归约串"，第 6 章 LR 分析整章都在精确回答它——详见第 5、6 章。

🔥 定义 2.8：短语、直接短语、句柄——课件第 38 页（教材 P31）

已知文法 G，文法开始符号 S，设 αβδ 是文法 G 的一个句型：

  • 🔥 短语：若 S ⇒* αAδ 且 A ⇒⁺ β，则称 β 是句型 αβδ 的相对于非终结符 A 的短语。
  • 🔥 直接短语：若有 S ⇒* αAδ 且 A ⇒ β（只用一条规则 A→β，一步直达），则称 β 是句型 αβδ 的相对于规则 A→β 的直接短语。
  • 🔥 句柄：一个句型的最左直接短语称为该句型的句柄。
白话版（对照语法树最好懂）：短语 = 树中某个非终结符结点整棵子树从左到右的叶子（相对那个结点）；直接短语 = 只有一层的子树（父结点一步就长出这些叶子，用的正是某条规则）；句柄 = 所有直接短语里最靠左的那个。自底向上分析每一步归约的就是句柄——第 6 章 LR 分析的核心任务就是"精确定位句柄"。

🔥 例：求句型 cabd 的短语、直接短语和句柄——课件第 39 页（完整解答）

题目（课件原题）：考虑文法 G[S]：S→cAd，A→ab | a，求句型 cabd 的短语、直接短语和句柄。分步解答：

第一步：画语法树（S 推 cAd 一步；其中的 A 只能用 A→ab 才能对上后面的 b）：

S
├─ c
├─ A
│  ├─ a
│  └─ b
└─ d        （从左到右读叶子：c a b d = cabd ✓）

第二步：逐个非终结符结点找子树产物（=短语）：

结点子树叶子（产物）是短语吗是直接短语吗
S（根）cabd✓ 相对于 S 的短语（S ⇒* S，S ⇒⁺ cabd 走两步）✗（S⇒cabd 需两步：S⇒cAd⇒cabd，不是一步）
A（中层）ab✓ 相对于 A 的短语（S ⇒* cAd，A ⇒⁺ ab）✓（恰好用规则 A→ab 一步：S ⇒* cAd 且 A ⇒ ab）

第三步：汇总作答：

短语：cabd（相对于 S）、ab（相对于 A）
直接短语：ab（相对于规则 A→ab）　——句型里只有这一个直接短语
句柄（最左直接短语）：ab

🔥 这就是自底向上分析归约 cabd 时"第一步先收 ab"的理论依据——句柄 ab 正是第 37 页例子里被先归约的那一段。

🔥 练习：句型 aabbaa 的短语、直接短语和句柄——课件第 40 页（完整分步解答）

题目（课件原题，三问）：考虑文法 G[S]：S→aAS | a，A→SbA | SS | ba：

第 1 问：求 G[S] 的 VN、VT 和识别符号。按"左部出现过的 = 非终结符，只在右部出现的 = 终结符"：

VN = { S, A }　　VT = { a, b }　　识别符号（开始符号）S = S（G[S] 方括号里那个）

第 2 问：文法 G[S] 有几条规则？竖线拆开数：S→aAS、S→a、A→SbA、A→SS、A→ba，共 5 条。

第 3 问：求句型 aabbaa 的短语、直接短语和句柄。分步：

① 先构造推导（草稿纸上试着让 S 吐出 aabbaa）：S ⇒ aAS ⇒ a(SbA)S ⇒ a(abA)S ⇒ a(ab·ba)S ⇒ aabbaa，逐条用的规则是 S→aAS、A→SbA、S→a、A→ba、S→a：

S ⇒ aAS        用 S→aAS
  ⇒ aSbAS      用 A→SbA
  ⇒ aabAS      用 S→a
  ⇒ aabbaS     用 A→ba
  ⇒ aabbaa     用 S→a      ✓ 得到句型 aabbaa

② 画语法树（课件第 40 页配了这棵树）：

S
├─ a
├─ A
│  ├─ S
│  │  └─ a
│  ├─ b
│  └─ A
│     ├─ b
│     └─ a
└─ S
   └─ a        （从左到右读叶子：a a b b a a = aabbaa ✓）

③ 逐个非终结符结点收短语、并判断是否"一层直达"：

结点（位置）子树产物短语（相对谁）直接短语（相对哪条规则）
S（根）aabbaa✓ 相对 S✗（S⇒aabbaa 共 5 步）
A（a 与最后的 a 之间）abba✓ 相对 A✗（A⇒abba 走 3 步：A→SbA→abA→abba）

🧹 2.7 有关文法在实际应用中的一些说明（课件第 41 页）

🔥 有害规则：U → U 应限制文法中不得含有——课件第 41 页

形如 U→U 的规则（左部右部一样）叫有害规则，写文法时应限制不得含有。为什么有害？做一遍课件的练习就懂了。

课件练习（原题三问）：G[A]: A→a，B→b：

(1) 求 VN、VT、P 和识别符号。

VN = { A, B }　VT = { a, b }　P = { A→a，B→b }　识别符号 = A

(2) 求 L(G[A])。分步：从开始符号 A 出发只有 A→a 一条路，A ⇒ a 就到头；B 虽有规则 B→b，但从 A 出发根本走不到 B（A 的推导里不会出现 B），所以 b 永远推不出来。故：

L(G[A]) = { a }

(3) 如果存在 A→A，该文法是不是二义性的？分步：加上 A→A 后，句子 a 就有了好多棵不同的语法树：

树1: A→a                          （一步）
树2: A⇒A→a                        （先 A→A 空转一圈，再 A→a）
树3: A⇒A⇒A→a                      （空转两圈再收尾）
……可以无限空转下去，同一个句子 a 对应无穷多棵不同的语法树
结论：是二义性文法。U→U 这种"原地转圈"的规则百无一用、徒增二义——所以叫有害规则，应限制文法中不得含有。

🔥 多余规则：应限制文法中不得含有多余规则——课件第 41 页

多余规则分两种情况（课件给的两行例子对照着看）：

类型含义课件例（G[A]: A→a，B→b | Dd，D→Df）
不可到达某非终结符从开始符号出发永远推导不出来，它的规则白写B：从 A 出发到不了 B（A→a 就终结了），所以 B→b 和 B→Dd 两条规则多余——上面练习(2)里 b 推不出来正是这个原因
不可终止某非终结符永远推不出全终结符的串，陷在里面出不来D：唯一的规则 D→Df 右部又含 D，转多少圈都甩不掉 D，推不出终结符串，所以 D→Df 多余；连带 B→Dd 里用到的 Dd 也跟着作废

🔥 判断套路（两句口诀）："从 S 往下走，走不到的是多余（不可到达）；从它自己往外走，出不去的是多余（不可终止）"。工程上压缩文法、考试里问"哪些规则可以删"都用这两条。

⭐ 上下文无关文法中的 ε 规则——课件第 41 页（了解级）
