✂️ 1. 词法分析器在干什么

🎯比喻：读英文文章时，你先做的不是理解句子，而是把 yo/​u/​are/good 这些单词一个个认出来、查词典。词法分析器（扫描器 Scanner）干的就是这个：把源程序的字符流切成一个个单词符号（Token），交给语法分析器当"单词"用。

词法分析器的功能与输出

🗣️ 人话版：词法分析器就是个"切单词、贴标签"的工人——左边吃进一长串字符，右边吐出一排小票，每张写着（这是哪类单词、值是什么）：把 for i := 1 切成（基本字,for）（标识符,i）（算符,:=）（常数,1）。它只管"认字"，不管"句子通不通"（那是语法分析的事）。

  • 主要功能：从左至右、从上至下逐字符扫描源程序，输出单词符号序列。
  • 其他功能：滤掉空格、跳过注释和换行符；行列计数（出错定位用）；发现并定位词法错误（非法字符）。
  • 与语法分析器的两种接口：① 独立一遍（简单但开销大）；② 作为语法分析器的子程序，随用随取（PL/0 采用，节省内存）。
  • 分离出词法分析的好处：编译器结构更简洁清晰、效率改进、可移植性增强。
单词符号分 5 类：基本字（关键字/保留字：for、if）｜标识符（变量名、过程名）｜常数（整型、实型）｜运算符（+ - * /）｜界符（; , ( )）
输出形式：二元式 （单词种别码，单词符号的属性值）；种别编码方式：一类一种 / 按类分种 / 一符一种（关键字常用）
描述词法规则的 5 种工具（课件清单）：EBNF（扩充 BNF）、正规文法（3型）、正规式、有限状态自动机、状态转换图——本章主角是中间三个，且它们可以互相转换

📐 2. 单词的数学描述：正规文法与正规式

正规文法（3型）描述单词

🗣️ 人话版：用文法拼单词，规矩是"每条规则只往前吐一个字符，最多再捎上一个还没展开的非终结符"——像报数一样一个一个来，绝不回头。

第1关讲过 3 型文法：A→aB 或 A→a。它能描述程序语言的单词结构：

<标识符> → l | l<字母数字>
<字母数字> → l | d | l<字母数字> | d<字母数字>
<无符号整数> → d | d<无符号整数>
l 代表任一字母，d 代表任一数字

正规式与正规集（重点）

🗣️ 人话版：正规式是写"单词配方"的通配符：竖线 |＝"或者"，星号 *＝"前面那坨重复任意遍（0 遍也行）"。一个正规式代表一整类长得像的串（这堆串就叫正规集）。为什么需要它？一行就能说清"标识符长什么样"，而且机器能自动把它变成识别程序（Lex 干的就是这个）。

正规式是用来描述单词结构的更紧凑写法；它表示的字符串集合叫正规集。递归定义（Σ 上）：

正规式正规集
ε、∅、a（a∈Σ）{ε}、∅、{a}
e₁|e₂（或）L(e₁)∪L(e₂)
e₁·e₂（连接，·可省）L(e₁)L(e₂)
e₁*（闭包）(L(e₁))*
运算优先级：* ＞ 连接 ＞ |
正规式（Σ={a,b}）正规集
a|b{a, b}
ab{ab}
a*{aⁿ|n≥0}（含 ε）
a*b{aⁿb|n≥0}
(a|b)*Σ* = 所有 a、b 串
a*b*{aⁿbᵐ|n,m≥0}

标识符 = (A|B)(A|B|0|1)*（以字母开头）；数 = (0|1)(0|1)*。
正规式等价：正规集相同则等价，记 U=V。经典等价式：b(ab)* = (ba)*b，(a|b)* = (a*b*)*。

🤖 3. 有穷自动机：会认单词的"小机器人"

🎯比喻：自动机就是一台"投币售货机式"的机器人：站在某个状态上，来一个字符就按规则跳到下一个状态；串读完了如果恰好站在终态（双圈），就说"这个词我认识（接受）"。

DFA vs NFA 定义对比（必考）

🗣️ 人话版：DFA 是没有选择困难症的机器人：站在任何状态、读任何字符，下一步去哪唯一确定；NFA 允许"分身"——同一个字符面前几条路都能走，还有不吃字符的"ε 传送门"。两者认串能力其实一样，但 NFA 要不停试错、没法直接写成程序，所以后面要把它"确定化"成 DFA。

DFA 确定的NFA 不确定的
五元组(K, Σ, f, S, Z)(K, Σ, f, S, Z)
f 映射K×Σ→K 单值K×Σ*→K 的子集（多值）
初态 S唯一一个非空初态集（可多个）
终态集 ZZ⊆KZ⊆K（可为空集）

直观特点：DFA——初态唯一、边上只有一个字符、无 ε 弧、一个状态对同一字符只有一条出边；NFA——初态不唯一、边上可以是串、可以含 ε 弧、同一字符可有多条出边。DFA 是 NFA 的特例；两者识别能力相同（对每个 NFA M 都存在 DFA M' 使 L(M)=L(M')）。

识别/接受：从初态出发，存在到某终态的通路，弧上标记连接起来恰好是 t ⇒ t 被识别，记 f(S,t)∈Z。DFA 初态同时是终态 ⇒ 可识别 ε；NFA 若存在某初态到某终态的 ε 通路，空字 ε 也可被识别。L(M)=自动机能识别的字的全体。NFA 识别慢（要试探多条路）、DFA 占空间大——所以要"确定化+最小化"。

状态转换矩阵（可考）：自动机除了画状态转换图，还可以写成矩阵——行=状态、列=输入字母、格=转向的状态（DFA 一格一个状态；NFA 一格一个状态集，ε 列也要写）。给你一个矩阵要会读出五元组和识别的串。如下面这个 DFA 模拟器的课件例，矩阵就是：行 S/U/V/Q，a 列填 U/Q/U/Q，b 列填 V/V/Q/Q（无转换的格记 —，表示报错）。

🧮 4. 子集法：NFA → DFA（考试大题重灾区）

🎯核心思想一句话：NFA 走到岔路口时"人格分裂"——DFA 的一个状态 = NFA 的一组状态（子集）。把"可能同时处在的所有 NFA 状态"打包当成一个新状态，不确定性就消失了。

两个基本运算（必须会手算）

🗣️ 人话版：把 ε 弧想成免费传送门：ε-closure(I)＝不吃任何字符、光靠传送门能到的所有位置——走 0 条传送门也算数，所以 I 自己永远在集合里；Move(I,a)＝真吃下一个字符 a 后能站的位置（这一步不顺传送门）。一句话区别：Move 只吃字符，Iₐ＝吃完字符还要免费传送一遍。

① ε-闭包 ε-closure(I)：从 I 中任一状态出发，经任意条 ε 弧能到达的状态全体（I 自身当然在内）
② Move(I, a)：从 I 中某状态出发经一条 a 弧到达的状态全体
③ Ia = ε-closure( Move(I, a) )　——子集法每步真正用的就是它

课件/教材例（教材 3.4 节那张 11 状态 NFA，状态 0~10，非本页实验室的图）：ε-closure({0}) = {0,1,2,4,7}；Move({0,1,2,4,7}, a) = {3,8}；ε-closure({3,8}) = {1,2,3,4,6,7,8}。下面实验室里你可以拿任意正规式自己算同类结果。

🔬 子集法全流程实验室（正规式 → NFA → DFA 一条龙）

选一个预置正规式（或自己写，支持 | * ( ) 和任意单字符），点"开工"看三步：
① Thompson 构造出 NFA → ② 子集法逐行确定化 → ③ 画出 DFA 并可测试任意串。

子集法手算流程（照这个套路写解题过程）

🗣️ 人话版：整个算法就是"广度优先登记户口"：从初态打包盒出发，对每个盒子挨个字母算出下一站；这个盒子见过就跳过，没见过就登记编号，直到再也冒不出新盒子为止。

  1. 预处理（若给的 NFA 初态/终态不唯一）：加新初态 X 指向所有初态、所有终态指向新终态 Y（都走 ε 弧）。
  2. 令 I₀ = ε-closure(初态集)，作为 DFA 初态。
  3. 对每个未标记的 I，逐个字母 a 求 Ia = ε-closure(Move(I,a))：得到新子集就编号登记，重复直到不再产生新子集。
  4. 含 NFA 终态的子集 = DFA 终态。
⚠️ 常见错误：算 Move 之后忘了再做 ε-闭包；把 I 本身忘在闭包外；漏掉"含终态的子集都是终态"。

🔬 迷你例：2 状态 NFA 完整走一遍子集法（先啃小例子，再做大题）

玩具 NFA（初态 0，终态 {1}）：0 —a→ 0、0 —a→ 1（读 a 两条路＝岔路口）、0 —ε→ 1（免费传送门）、1 —b→ 1，识别 a*b*。

步当前子集 I① 先 Move（吃一个字符）② 再 ε-闭包＝Iₐ【旁注】这步在干嘛
0闭包({0})＝I₀—{0,1}开局只做闭包：0 自己（走 0 条 ε 也算）＋传送门到的 1；含终态 ⇒ DFA 初态即终态，能认 ε
1{0,1} 读 a{0,1}{0,1}＝I₀0 吃 a 可留原地也可去 1，分身全部打包；没冒出新子集，不必登记
2{0,1} 读 b{1}{1}＝I₁ ★新只有 1 认识 b；{1} 头一次见 → 登记新状态；含终态 ⇒ DFA 终态
3{1} 读 a∅—{1} 上没有 a 弧，死路；转换表这格填 "—"（读 a 报错）
4{1} 读 b{1}{1}＝I₁绕回自己；再无新子集 ⇒ 算法结束：2 状态 NFA → 2 状态 DFA
💡 看：DFA 的状态不再是 0、1，而是 {0,1}、{1} 这样的打包盒——岔路口的所有可能一次揣进兜里，每读一个字符结果仍是一个确定的盒子，"不确定"就是这么被消掉的。

✨ 5. DFA 最小化：分割法

🎯比喻：给一群机器人"查户口"分宿舍。先按"是不是终态"分成两栋楼（一致性），再在每个楼里按"收到 a、b 后去的楼号是否相同"继续细分（蔓延性），直到每间房里的人行为完全一致，每房派一个代表即可。

等价状态两条件 + 分割法四步

🗣️ 人话版：最小化＝给状态"查重合并"：两个状态无论以后喂什么串，接受/拒绝的结果永远相同（＝等价），留一个就够。怎么查？先按终态/非终态分成两栋楼（成绩单都不同的，一眼拆开——这叫一致性）；再反复检查每间房里的人"读 a、读 b 后进的楼号"是否相同，不同就分家（这叫蔓延性）；分到不能再分，每间房派一个代表。

  • 状态 s、t 等价 ⇔ ① 一致性：同终态或同非终态；② 蔓延性：对一切输入符号，s、t 转到等价状态里。
  • 先删多余状态：不可到达状态（从初态永远到不了）、不可终止状态（到不了终态）。
  • 四步：① 分成终态集 / 非终态集 → ② 对每个子集，看各状态经每个字母转向的目标落在哪个子集，目标子集不同就分裂 → ③ 重复②直到不再分裂 → ④ 每个子集选一个代表合并；含原初态的子集代表是新初态，含原终态的都是终态。

🔬 迷你例：4 状态 DFA 逐轮分割（每轮旁注）

玩具 DFA（初态 A，终态 {D}）：A: a→B, b→C；B: a→B, b→D；C: a→B, b→D；D: a→D, b→D。

轮次动作分割结果【旁注】为什么这么分
第0轮按终态分堆{A,B,C} ｜ {D}一致性：D 是终态（双圈），先和普通人分两栋楼
第1轮逐个查 {A,B,C} 的去向{A} ｜ {B,C} ｜ {D}蔓延性：读 a 大家都进 {A,B,C}，不分；读 b 时 A→C（非终态楼）、B/C→D（终态楼）——A 表现不同，分家
第2轮复查各堆不再分裂{B,C}：读 a 都到 B、读 b 都到 D，去的楼相同 ⇒ B、C 行为完全一致，等价
合并每堆留一个代表剩 3 个状态B、C 合成一个；含 A 的堆代表当新初态，含 D 的堆都是终态

正规文法 ↔ 自动机 的转换规则（3.6节，选择题常考）

🗣️ 人话版：文法推导和自动机走图，本来就是同一件事的两种说法：A→aB 读作"状态 A 吃了字符 a 就到状态 B"，A→a 读作"状态 A 吃完 a 就到终点"。所以每个非终结符＝一个状态，再新设一个终点 Z，收留所有"A→a"式的收尾。

正规文法 G → FA M：字母表 = G 的终结符集；每个非终结符对应一个状态，开始符号为初态；另加一个新终态 Z；
　规则 A→tB ⇒ f(A,t)=B；　规则 A→t ⇒ f(A,t)=Z
FA M → 正规文法：f(A,t)=B（B≠Z）⇒ A→tB；　f(A,t)=Z ⇒ A→t
💡 能力等价链条（背！）：正规式 ⇔ 正规文法 ⇔ NFA —子集法→ DFA —合并等价状态→ 最简DFA。它们在接收语言的能力上完全等价，DFA 可直接编程实现。
